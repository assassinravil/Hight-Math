Мнимая единица и алгебраическая форма

Зачем это придумали

Уравнение x² + 1 = 0 не имеет решений среди действительных чисел: квадрат никогда не бывает отрицательным. Чтобы такие уравнения всё же решались, вводят новое число — мнимую единицу i, у которой по определению i² = −1.

Определение
i² = −1

Степени i идут по кругу с периодом 4:

i¹ = i,   i² = −1,   i³ = −i,   i⁴ = 1,   i⁵ = i, …

Алгебраическая форма комплексного числа: z = a + bi, где a = Re z (действительная часть), b = Im z (мнимая часть).

Действия в алгебраической форме

Сложение — покомпонентно; умножение — раскрываем скобки и всюду заменяем i² на −1.

(1 + 2i)(3 + i) = 3 + i + 6i + 2i² = 3 + 7i + 2·(−1) = 1 + 7i

Сопряжённое число и модуль

Сопряжённое к z = a + bi — это z̄ = a − bi (отражение точки относительно оси Re). Его ключевое свойство:

z · z̄ = (a + bi)(a − bi) = a² − (bi)² = a² + b²

Результат — действительное число, равное квадрату длины вектора. Отсюда модуль:

|z| = √(a² + b²)

Именно поэтому при делении домножают на сопряжённое знаменателя: z1z2 = z1·z̄2z2·z̄2 — знаменатель становится действительным.

Число как точка и как вектор

Интуиция

Комплексное число z = a + bi — это точка на плоскости с координатами (a; b), или вектор из начала координат в эту точку. Ось x — действительная часть (Re), ось y — мнимая (Im).

Формы записи

Алгебраическая: z = a + bi.   Модуль r = |z| = √(a² + b²) — длина вектора.   Аргумент φ = arg z — угол вектора с осью Re.

z = r(cos φ + i·sin φ)  — тригонометрическая форма

Интерактив: тяни точку z по плоскости

Модуль — длина стрелки, аргумент — её угол. Точка притягивается к узлам сетки (шаг 0,25).

Как из a + bi получить тригонометрическую форму

Смотрим на прямоугольный треугольник со сторонами a и b и гипотенузой r. Из него:

a = r·cos φ,   b = r·sin φ   ⇒   z = a + bi = r·cos φ + i·r·sin φ = r(cos φ + i·sin φ)

Модуль берём по Пифагору: r = √(a² + b²). А угол — из отношения сторон: tg φ = ba.

Ловушка аргумента

Формула φ = arctg(ba) даёт верный угол только в правой полуплоскости (a > 0). Причина: arctg всегда возвращает угол в (−π/2, π/2), а точка может быть слева. Поэтому нужно смотреть на четверть:

Где точкаАргумент φ
a > 0 (I и IV четв.)arctg(b/a)
a < 0, b ≥ 0 (II четв.)arctg(b/a) + π
a < 0, b < 0 (III четв.)arctg(b/a) − π

Пример, где наивный arctg обманывает

z = −1 − i  (III четверть). r = √(1 + 1) = √2.
Наивно: arctg(−1−1) = arctg(1) = π4 — но это указывает в I четверть, а точка в III!
Верно: φ = π4 − π = −3π4. Итог: z = √2·(cos(−3π4) + i·sin(−3π4)).

В твоём конспекте пример z = 1 + i дал φ = arctg 1 = π/4 — и это верно именно потому, что 1 + i лежит в I четверти. Проверяй четверть каждый раз (в интерактиве выше аргумент всегда считается правильно — можешь потянуть точку влево-вниз и сравнить).

Умножение как поворот и растяжение

Интуиция

Когда перемножают два комплексных числа, их длины перемножаются, а углы складываются. То есть умножение на число — это «повернуть и растянуть» вектор. Это и есть главная геометрическая идея комплексных чисел.

z1·z2 = r1r2·(cos(φ1+φ2) + i·sin(φ1+φ2))
Почему так — вывод

Возьмём z1 = r1(cos φ1 + i·sin φ1), z2 = r2(cos φ2 + i·sin φ2) и просто перемножим скобки:

z1z2 = r1r2·(cos φ1 + i·sin φ1)(cos φ2 + i·sin φ2)
= r1r2·[cos φ1cos φ2 + i·cos φ1sin φ2 + i·sin φ1cos φ2 + i²·sin φ1sin φ2]
= r1r2·[(cos φ1cos φ2 − sin φ1sin φ2) + i·(sin φ1cos φ2 + cos φ1sin φ2)]   (использовали i² = −1)
По формулам сложения углов скобки — это cos(φ1+φ2) и sin(φ1+φ2):
= r1r2·(cos(φ1+φ2) + i·sin(φ1+φ2))   ∎

Видно прямо из выкладки: модули перемножились (r1r2), а аргументы сложились (φ1+φ2). Это и есть «повернуть и растянуть».

Деление — наоборот: длины делятся, углы вычитаются: z1z2 = r1r2·(cos(φ1−φ2) + i·sin(φ1−φ2)).

Интерактив: тяни z₁ и z₂, смотри на произведение

Синий — z₁, розовый — z₂, зелёный — произведение. Замечай: угол зелёного = сумма углов, длина = произведение длин.

Возведение в степень — формула Муавра

Интуиция

Умножить число само на себя n раз — значит повернуть вектор на угол nφ и растянуть в rn раз. Если число лежит на единичной окружности (r = 1), степень — это чистый поворот по кругу.

Формула Муавра
zn = rn·(cos nφ + i·sin nφ)
Почему так — вывод

Степень — это повторное умножение, а при каждом умножении (см. предыдущий раздел) модули перемножаются, а аргументы складываются. Разгоним по шагам:

z² = z·z: модуль r·r = r², аргумент φ + φ = 2φ  →  z² = r²(cos 2φ + i·sin 2φ).
z³ = z²·z: модуль r²·r = r³, аргумент 2φ + φ = 3φ  →  z³ = r³(cos 3φ + i·sin 3φ).
…и так далее: за n шагов модуль стал rn, аргумент — nφ (строго это доказывают по индукции). ∎

Интерактив: степени числа z

Точки z¹, z², … zn ложатся по спирали (или по окружности при r = 1). Последняя, zn, выделена.

Корни — вершины правильного n-угольника

Интуиция

У числа ровно n корней n-й степени. Все они одной длины n√r, поэтому лежат на одной окружности и делят её на равные части — то есть образуют правильный n-угольник.

Формула корней
n√z = n√r ·(cos φ+2πkn + i·sin φ+2πkn),   k = 0, 1, …, n−1
Откуда берётся формула — вывод

Корень n-й степени из z — это число w, для которого wn = z. Ищем его тоже в тригонометрической форме: w = ρ(cos ψ + i·sin ψ). По формуле Муавра:

wn = ρn(cos nψ + i·sin nψ), и это должно равняться z = r(cos φ + i·sin φ).
Модули равны: ρn = r  ⇒  ρ = n√r (обычный арифметический корень из положительного числа — он единственный).
Ключевой момент: углы у равных чисел совпадают с точностью до 2π (полный оборот ничего не меняет). Поэтому nψ = φ + 2πk, где k — любое целое.
Отсюда ψ = φ + 2πkn.
Разные k дают разные углы, пока k = 0, 1, …, n−1. При k = n угол вырастает на 2πnn = 2π — то есть возвращается к корню с k = 0. Значит различных корней ровно n. ∎

Все корни имеют одинаковый модуль n√r (лежат на одной окружности), а их углы отличаются на 2πn — вот почему они делят окружность поровну и образуют правильный n-угольник.

Интерактив: корни числа z

Тяни z (жёлтая точка), меняй n. Красные точки — корни, соединённые в n-угольник.

Разобранный пример: ⁴√(1 + i)

Показать решение

z = 1 + i: r = √(1²+1²) = √2, φ = arctg(1/1) = π/4.

Корней 4, они на окружности радиуса 4√(√2) = 21/8 = 8√2. Углы: (π/4 + 2πk)/4.

  • k=0: угол π/16 → z0 = 8√2·(cos π/16 + i·sin π/16)
  • k=1: угол 9π/16 → z1
  • k=2: угол 17π/16 → z2
  • k=3: угол 25π/16 → z3

Четыре точки образуют квадрат — нажми кнопку выше, чтобы увидеть.

Задачи для студентки

Сначала представь число на плоскости (куда смотрит вектор, какой длины), потом считай.

1. Найди модуль и аргумент числа z = −1 + i√3.

Ответ

r = √(1 + 3) = 2; точка во II четверти, φ = 2π/3 (120°).

2. Перемножь z1 = 2(cos 30° + i·sin 30°) и z2 = 3(cos 60° + i·sin 60°).

Ответ

Длины: 2·3 = 6. Углы: 30° + 60° = 90°. Ответ: 6(cos 90° + i·sin 90°) = 6i.

3. Вычисли (1 + i)8 по формуле Муавра.

Ответ

r = √2, φ = 45°. (1+i)8 = (√2)8·(cos 360° + i·sin 360°) = 16·1 = 16.

4. Найди все корни ³√8 и покажи их на плоскости.

Ответ

r = 8, 3√8 = 2; углы (0 + 2πk)/3, k = 0,1,2 → 0°, 120°, 240°. Корни: 2, −1 + i√3, −1 − i√3 — вершины равностороннего треугольника. Проверь в интерактиве (тяни z на 8 по оси Re, n = 3).
