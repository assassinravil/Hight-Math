Множества

Что такое множество, конечные и бесконечные, мощность, счётные и несчётные, подмножества.

Интуиция

Множество — это набор объектов, объединённых каким-то признаком: числа, точки, буквы, что угодно. Объекты называют элементами. Запись x ∈ A читается «x принадлежит A».

Определение

Множество — совокупность элементов, объединённых некоторым признаком. Задают перечислением A = {a, b, c} или условием.

Конечные и бесконечные, мощность

Определения

Конечное множество содержит конечное число элементов; бесконечное — элементы нельзя пересчитать. Мощность |A| конечного множества — число его элементов.

Пример A = {a, b, c} ⇒ |A| = 3. Множество всех натуральных чисел ℕ бесконечно.

Счётные и несчётные

Определения

Счётное множество — то, которое можно занумеровать (поставить в соответствие натуральные числа), например ℕ = {1, 2, 3, …}. Несчётное — занумеровать нельзя; таково множество всех вещественных чисел ℝ.

Пример ℕ и даже ℚ (рациональные) — счётны. А отрезок [0, 1] действительных чисел — несчётен.

Подмножества

Определение

Если все элементы B принадлежат A, то B — подмножество A: B ⊂ A.

Пример {1, 2} ⊂ {1, 2, 3}. Также ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ.

Операции над множествами

Объединение, пересечение, разность, дополнение; свойства отношения ⊂.

Определения
  • Объединение A ∪ B = { x : x ∈ A или x ∈ B } — всё, что хотя бы в одном.
  • Пересечение A ∩ B = { x : x ∈ A и x ∈ B } — общее.
  • Разность A \ B = { x : x ∈ A, x ∉ B } — то, что в A, но не в B.
  • Дополнение Ac = { x : x ∉ A, x ∈ U } — всё из универсума U, что не в A.
Исправлено (в конспекте описка): в дополнении условие — x ∉ A (а не x ∈ A): дополнение состоит из элементов, которые в A не входят.

Интерактив: диаграммы Венна

Нажимай операции — подсветится соответствующая область.

Пример A = {1, 2}, B = {2, 3}:   A ∪ B = {1, 2, 3},   A ∩ B = {2},   A \ B = {1},   B \ A = {3}.

Свойства отношения ⊂

  • Рефлексивность: A ⊂ A.
  • Антисимметричность: если A ⊂ B и B ⊂ A, то A = B.
  • Транзитивность: если A ⊂ B и B ⊂ C, то A ⊂ C.

Множества на числовой прямой

Окрестность точки, открытые и замкнутые множества, точные грани.

Окрестность точки

Определения

Окрестность точки a — любой открытый интервал, содержащий a. δ-окрестность: Uδ(a) = (a − δ, a + δ). Проколотая δ-окрестность — та же без самой точки a: U̇δ(a) = (a − δ, a) ∪ (a, a + δ).

Исправлено: пример δ = 0,01, a = 1 даёт Uδ(1) = (0,99; 1,01) — в конспекте второй конец не был дописан.

Интерактив: δ-окрестность

Открытые и замкнутые множества

Определения

Открытое множество: каждая его точка внутренняя — у любой точки найдётся окрестность, целиком лежащая в множестве. Пример — интервал (a, b). Замкнутое множество содержит все свои граничные точки. Пример — отрезок [a, b].

Пример (0, 1) — открытое (концы не входят). [0, 1] — замкнутое (концы входят). [0, 1) — ни то, ни другое.

Свойства

  • Объединение любого числа открытых множеств — открыто.
  • Пересечение любого числа замкнутых множеств — замкнуто.

Точные грани (sup и inf)

Определения

Верхняя грань множества A — число M, такое что a ≤ M для всех a ∈ A. Точная верхняя грань (sup) — наименьшая из верхних граней. Аналогично нижняя грань (a ≥ m) и точная нижняя (inf) — наибольшая из нижних.

Пример Для интервала (0, 1): sup = 1, inf = 0 — при этом сами эти значения множеству не принадлежат (грань не обязана достигаться).

Отображения и функции

Отображение множеств, инъекция/сюръекция/биекция, функция вещественной переменной, сложная и обратная функции.

Определение

Отображение f: X → Y — правило, по которому каждому элементу множества X ставится в соответствие элемент множества Y.

Три важных типа
  • Инъекция: разным элементам X соответствуют разные элементы Y (никакие два x не «слипаются» в один y).
  • Сюръекция: каждый элемент Y является образом хотя бы одного x (Y «покрыт» весь).
  • Биекция: взаимно однозначное соответствие — одновременно инъекция и сюръекция (каждому x — свой единственный y и наоборот).

Интерактив: типы отображений

Функция вещественной переменной

Определение

Функция f: D → E (D, E ⊂ ℝ), y = f(x) — закон, ставящий в соответствие каждому x ∈ D число y ∈ E. Виды: чётные/нечётные, периодические, монотонные.

Сложная и обратная функции

Сложная функция

Если y = f(u), а u = φ(x), то y = f(φ(x)) — сложная функция; φ(x) называют промежуточным аргументом.

Пример y = √(sin x): внешняя функция f(u) = √u, внутренняя u = φ(x) = sin x.
Обратная функция

Если y = f(x) задаёт биекцию f: X → Y, то существует обратная g: Y → X, возвращающая x по y: x = g(y).

Обратная функция существует именно тогда, когда исходная — биекция (каждому y отвечает ровно один x). Поэтому три типа отображений выше так важны.
