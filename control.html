№1. Исследовать на непрерывность

Дано
y = 13x + 1 · arctg 1x − 2
Решение по шагам
Шаг 1. Где может ломаться. Функция составлена из элементарных и непрерывна всюду, кроме точек, где знаменатели обращаются в ноль:  3x + 1 = 0 ⟹ x = −1/3;  x − 2 = 0 ⟹ x = 2.
Шаг 2. Точка x = −1/3. Множитель 1/(3x+1) → ∞. Второй множитель в этой точке конечен: arctg(1/(−1/3 − 2)) = arctg(−3/7) ≈ −0,40 ≠ 0.
Значит произведение → ∞ ⟹ это разрыв 2-го рода (бесконечный, вертикальная асимптота).
Шаг 3. Точка x = 2. Здесь «опасен» arctg(1/(x−2)): дробь 1/(x−2) при подходе слева и справа ведёт себя по-разному.
Слева (x→2−0): x−2 → 0⁻, 1/(x−2) → −∞,  arctg(−∞) = −π/2. Множитель 1/(3x+1) → 1/7. Левый предел: (1/7)·(−π/2) = −π/14.
Справа (x→2+0): x−2 → 0⁺, 1/(x−2) → +∞,  arctg(+∞) = +π/2. Правый предел: (1/7)·(π/2) = +π/14.
Пределы конечны, но не равны ⟹ разрыв 1-го рода (скачок). Величина скачка: π/14 − (−π/14) = π/7.
Две особые точки: при x=−1/3 — бесконечный разрыв (асимптота), при x=2 — конечный скачок π/7.
Ответ: x = −1/3 — разрыв 2-го рода; x = 2 — разрыв 1-го рода (скачок π/7); в остальных точках функция непрерывна.
Проверка: (1) в x=−1/3 один множитель бесконечен, другой конечен ≠ 0 ⟹ произведение бесконечно — верно II род. (2) В x=2 оба односторонних предела конечны (±π/14) и различны ⟹ верно I род. Знак скачка: справа больше, чем слева, π/7 > 0 — согласовано.

№2. Вычислить производную

Дано
y = 3√( arctg(ln x + √x) ) = ( arctg(ln x + √x) )1/3
Решение по шагам (цепное правило, 3 слоя)
Слои: внешний — степень (…)1/3; средний — arctg(…); внутренний — u = ln x + √x.
Шаг 1. Внешний. ((arctg u)1/3)′ = 13(arctg u)−2/3 · (arctg u)′.
Шаг 2. Средний. (arctg u)′ = u′1 + u².
Шаг 3. Внутренний. u′ = (ln x + √x)′ = (ln x)′ + (√x)′.  (ln x)′ = 1x;  (√x)′ = (x1/2)′ = 12x−1/2 = 12√x.  Итого u′ = 1x + 12√x.
Шаг 4. Перемножаем все три слоя (внешний × средний × внутренний): y′ = 13(arctg u)−2/3 · 11+u² · u′, где u = ln x + √x. Расписываем:
y′ = 1x + 12√x3 · 3√( arctg²(ln x + √x) ) · (1 + (ln x + √x)²)
Ответ: y′ = (1/x + 1/(2√x)) / [ 3·∛(arctg²(ln x+√x))·(1 + (ln x+√x)²) ].
Проверка: считаем «снаружи внутрь» и на каждом слое домножаем на производную начинки — три множителя, три слоя. Степень −2/3 даёт корень в знаменателе (∛arctg²), arctg даёт (1+u²) в знаменателе, внутренняя часть — скобку 1/x+1/(2√x). Размерности совпадают.

№3. Вычислить производную

Дано
y = sin³x · (x + 3)⁵ · √(logₐ x)3√(x + 8)
Решение по шагам (логарифмическое дифференцирование)
Почему так: тут произведение и частное степеней. Напрямую дифференцировать тяжело, а логарифм превращает произведение в сумму, а степени — в множители. После логарифмирования каждое слагаемое дифференцируется легко.
Шаг 1. Перепишем корни как степени (чтобы увидеть показатели):  √(logₐx) = (logₐx)1/2,  3√(x+8) = (x+8)1/3 (в знаменателе — показатель −1/3).
y = sin³x · (x+3)⁵ · (logₐx)1/2 · (x+8)−1/3.
Шаг 2. Логарифмируем. ln(произведения) = сумма логарифмов, ln(aᵏ) = k·ln a:
ln y = 3 ln(sin x) + 5 ln(x+3) + 12 ln(logₐx) − 13 ln(x+8)
Шаг 3. Дифференцируем левую часть. ln y — сложная функция от x (ведь y = y(x)):  (ln y)′ = 1y·y′ = y′y.
Шаг 4. Дифференцируем правую часть — каждое слагаемое отдельно, по действиям.
① член 3 ln(sin x). Выносим 3, (ln u)′ = u′/u с u = sin x:  3·(sin x)′sin x = 3·cos xsin x = 3 ctg x.
② член 5 ln(x+3). u = x+3, u′ = 1:  5·(x+3)′x+3 = 5·1x+3 = 5x+3.
③ член ½ ln(logₐx). Здесь «логарифм от логарифма» — снова (ln u)′ = u′/u, но теперь u = logₐx:
= 12·(logₐx)′logₐx.  Производная (logₐx)′ = 1x·ln a, а само logₐx = ln xln a.
Подставляем: 12·1/(x ln a)ln x/ln a = 12·1x ln a·ln aln x = 12·1x ln x = 12x ln x.  (ln a сократился!)
④ член −⅓ ln(x+8). u = x+8, u′ = 1:  −13·1x+8 = −13(x+8).
Шаг 5. Собираем правую часть:
y′y = 3 ctg x + 5x+3 + 12x ln x − 13(x+8)
Шаг 6. Умножаем на y (возвращаем сам y из условия):
y′ = sin³x·(x+3)⁵·√(logₐx)3√(x+8)·( 3 ctg x + 5x+3 + 12x ln x − 13(x+8) )
Ответ: y′ = y·( 3 ctg x + 5/(x+3) + 1/(2x ln x) − 1/(3(x+8)) ), где y — исходная функция.
Проверка: (1) в скобке 4 слагаемых = 4 множителя в y — ничего не потеряли, знаки «+ + + −» отвечают множителям в числителе и в знаменателе. (2) Член ③ при a = e: logₑx = ln x, (½ ln ln x)′ = ½·(1/ln x)·(1/x) = 1/(2x ln x) — тот же результат. (3) Член ① через ctg: 3·cos x/sin x — пересчитал, верно.

№4. Вычислить производную

Дано
y = ( sin(x + 2) )1/cos x
Решение по шагам
Почему лог-дифференцирование: переменная и в основании, и в показателе.
Шаг 1. Логарифмируем: ln y = 1cos x·ln(sin(x+2)).
Шаг 2. Дифференцируем правую часть как произведение u·v, где u = ln(sin(x+2)), v = (cos x)−1.
u′ = cos(x+2)sin(x+2) = ctg(x+2);   v′ = −(cos x)−2·(−sin x) = sin xcos²x.
Шаг 3. (ln y)′ = u′v + uv′ = ctg(x+2)cos x + ln(sin(x+2))·sin xcos²x.
Шаг 4. y′ = y·(ln y)′.
Ответ: y′ = (sin(x+2))1/cos x·( ctg(x+2)cos x + sin x·ln(sin(x+2))cos²x ).
Проверка: (1) два слагаемых — от «производной показателя» и «производной основания», как и должно быть у степенно-показательной. (2) Производная (1/cos x) = sin x/cos²x — это sec x·tg x, верно. (3) При постоянном показателе (если бы 1/cos x = const) остался бы только первый член — логика сходится.

№5. Производная параметрической функции

Дано
x = t·arctg t,    y = t·arcctg t.   Найти y′x.
Решение по шагам
Формула: y′x = y′tx′t.
Шаг 1. x′t (произведение): = arctg t + t·11+t² = arctg t + t1+t².
Шаг 2. y′t (произведение, (arcctg t)′ = −1/(1+t²)): = arcctg t + t·(−11+t²) = arcctg t − t1+t².
Шаг 3. Делим:
y′x = arcctg t − t/(1+t²)arctg t + t/(1+t²)
Ответ: y′x = (arcctg t − t/(1+t²)) / (arctg t + t/(1+t²)).
Проверка: (1) обе производные найдены по правилу произведения — по два слагаемых. (2) Отличие числителя и знаменателя только в «arcctg vs arctg» и знаке у t/(1+t²) — это прямое следствие того, что производные arctg и arcctg различаются лишь знаком. Согласовано.

№6. Производная неявной функции

Дано
√(3x² − y²) = arcsin xy,   y = y(x).
Решение по шагам
Идея: дифференцируем обе части по x, помня, что y = y(x) (поэтому у каждого y при дифференцировании появляется множитель y′). Потом выражаем y′.
Шаг 1. Дифференцируем левую часть √(3x²−y²) = (3x²−y²)1/2 — сложная функция:
= 12(3x²−y²)−1/2·(3x²−y²)′.  Внутри: (3x²)′ = 6x, (y²)′ = 2y·y′ ⟹ (3x²−y²)′ = 6x − 2y·y′.
Получаем: 6x − 2y·y′2√(3x²−y²). Сокращаем 2 в числителе и знаменателе:  левая часть = 3x − y·y′√(3x²−y²).
Шаг 2. Дифференцируем правую часть arcsin(x/y). Формула (arcsin u)′ = u′/√(1−u²) с u = x/y.
2a. Производная внутренней u = x/y (частное, y = y(x)): u′ = (x)′·y − x·(y)′y² = 1·y − x·y′y² = y − x·y′y².
2b. Считаем √(1 − u²) = √(1 − x²/y²). Приводим под корнем к общему знаменателю: 1 − x²y² = y² − x²y².
Извлекаем корень: √(y²−x²y²) = √(y²−x²)y.  Вот откуда берётся √(y²−x²) — это √(1−x²/y²) после приведения к общему знаменателю.
2c. Собираем правую часть: u′√(1−u²) = (y−x·y′)/y²√(y²−x²)/y = y − x·y′y²·y√(y²−x²) = y − x·y′y·√(y²−x²).
Шаг 3. Приравниваем левую и правую части:
3x − y·y′√(3x²−y²) = y − x·y′y·√(y²−x²)
Шаг 4. Избавляемся от дробей — умножаем крест-накрест:
(3x − y·y′)·y·√(y²−x²) = (y − x·y′)·√(3x²−y²).
Раскроем скобки:  3xy√(y²−x²) − y²·y′·√(y²−x²) = y√(3x²−y²) − x·y′·√(3x²−y²).
Шаг 5. Собираем всё с y′ в одну сторону, остальное — в другую:
x·y′·√(3x²−y²) − y²·y′·√(y²−x²) = y√(3x²−y²) − 3xy√(y²−x²).
Выносим y′:  y′·( x√(3x²−y²) − y²√(y²−x²) ) = y√(3x²−y²) − 3xy√(y²−x²).
Шаг 6. Делим — получаем y′:
y′ = y√(3x²−y²) − 3xy√(y²−x²)x√(3x²−y²) − y²√(y²−x²)
Ответ: y′ = (y√(3x²−y²) − 3xy√(y²−x²)) / (x√(3x²−y²) − y²√(y²−x²)).
Проверка: (1) слева двойка из (3x²−y²)′ = 6x−2yy′ сократилась с двойкой корня — верно. (2) Корень √(y²−x²) честно получен из √(1−x²/y²) (Шаг 2b). (3) Все члены с y′ собраны слева, без y′ — справа; выносится y′ в скобку — алгебра замкнулась. Ответ выражен только через x и y, как и положено для неявной функции.

№7. Касательная и нормаль

Дано
y = (3 + 2x²)·e5x,   точка x₀ = 0.
Решение по шагам
Шаг 1. Значение в точке. f(0) = (3 + 0)·e⁰ = 3. Точка касания M(0, 3).
Шаг 2. Производная по правилу произведения (uv)′ = u′v + uv′, где u = 3 + 2x², v = e5x.
u′ = (3 + 2x²)′ = 4x;   v′ = (e5x)′ = e5x·(5x)′ = 5e5x.
f′(x) = 4x·e5x + (3 + 2x²)·5e5x = e5x·(4x + 15 + 10x²) = e5x(10x² + 4x + 15).
Шаг 3. Наклон в точке. Подставляем x = 0: f′(0) = e⁰·(0 + 0 + 15) = 1·15 = 15.
Шаг 4. Касательная y = f(0) + f′(0)(x − 0):  y = 3 + 15x ⟹ y = 15x + 3.
Шаг 5. Нормаль (наклон −1/f′(0) = −1/15):  y = 3 − 115x ⟹ y = −x/15 + 3.
Касательная и нормаль пересекаются в M(0,3) под прямым углом: произведение наклонов 15·(−1/15) = −1.
Ответ: касательная y = 15x + 3;  нормаль y = −x/15 + 3.
Проверка: (1) обе прямые проходят через M: при x=0 обе дают y=3 ✓. (2) Перпендикулярность: 15·(−1/15) = −1 ✓. (3) f′(0): 4·0·1 + 3·5·1 = 15 — пересчитал прямой подстановкой, совпало.

№8. Предел по правилу Лопиталя

Дано
limx→0 ( 1x − 1arcsin x )
Решение по правилу Лопиталя (по шагам)
Шаг 1. Смотрим, что за неопределённость. При x → 0: 1/x → ∞ и 1/arcsin x → ∞, значит разность — вид ∞ − ∞. Лопиталь напрямую к нему не применяют — сначала сводим к дроби.
Шаг 2. Общий знаменатель. 1x − 1arcsin x = arcsin x − xx·arcsin x.
Шаг 3. Проверяем вид дроби. Числитель: arcsin 0 − 0 = 0. Знаменатель: 0·arcsin 0 = 0. Значит это 00 — теперь можно применять Лопиталь (производная числителя делить на производную знаменателя).
Шаг 4. Первое применение Лопиталя. Дифференцируем отдельно верх и низ.
Числитель: (arcsin x − x)′ = (arcsin x)′ − (x)′ = 1√(1−x²) − 1.
Знаменатель (произведение): (x·arcsin x)′ = (x)′·arcsin x + x·(arcsin x)′ = arcsin x + x√(1−x²).
Предел стал: limx→0 1/√(1−x²) − 1arcsin x + x/√(1−x²).
Шаг 5. Подставляем x = 0. Числитель: 1/1 − 1 = 0. Знаменатель: 0 + 0 = 0. Снова 00 ⟹ применяем Лопиталь ещё раз.
Шаг 6. Второе применение. Числитель (1−x²)−1/2 − 1:  производная = −12(1−x²)−3/2·(−2x) = x(1−x²)3/2.
Знаменатель arcsin x + x(1−x²)−1/2:  = 1√(1−x²) + [1·(1−x²)−1/2 + x·x(1−x²)3/2] = 2√(1−x²) + x²(1−x²)3/2.
Шаг 7. Подставляем x = 0. Числитель: 0/1 = 0. Знаменатель: 2/1 + 0 = 2.
Предел = 02 = 0.
Ответ: предел равен 0.
Проверка: (1) Численно при x = 0,1: 1/0,1 − 1/arcsin 0,1 = 10 − 1/0,100167 ≈ 10 − 9,9833 ≈ 0,017 → близко к 0; при x = 0,05 получится ещё меньше ≈ 0,004 — убывает к 0. (2) Через эквивалентность (для контроля): arcsin x ≈ x + x³/6, числитель ≈ x³/6, знаменатель ≈ x², отношение ≈ x/6 → 0. Оба подтверждают ответ 0.

№9. Общая формула n-й производной

Дано
y = x³·ln(5x)
Решение по шагам
Идея: общую формулу не угадывают с потолка — сначала честно считаем первые производные, ловим закономерность, а затем записываем yⁿ. Полезный факт: ln(5x) = ln 5 + ln x, поэтому (ln 5x)′ = 0 + 1/x = 1x.
Шаг 1. y′ — правило произведения для x³·ln5x:
y′ = (x³)′·ln5x + x³·(ln5x)′ = 3x²·ln5x + x³·1x = 3x²·ln5x + x².
Шаг 2. y″ — дифференцируем каждое слагаемое. Первое (3x²·ln5x) — снова произведение:
(3x²·ln5x)′ = 6x·ln5x + 3x²·1x = 6x·ln5x + 3x.  Второе: (x²)′ = 2x.
y″ = 6x·ln5x + 3x + 2x = 6x·ln5x + 5x.
Шаг 3. y‴. (6x·ln5x)′ = 6·ln5x + 6x·1x = 6 ln5x + 6.  (5x)′ = 5.
y‴ = 6 ln5x + 6 + 5 = 6 ln5x + 11.
Шаг 4. y⁗. (6 ln5x)′ = 6·1x = 6x,  (11)′ = 0.  ⟹ y⁗ = 6x = 6x−1. Важно: логарифм исчез! Дальше дифференцируем чистую степень 6x⁻¹.
Шаг 5. Считаем дальше и смотрим на закономерность (производная xᵏ = k·xᵏ⁻¹):
y⁽⁵⁾ = (6x⁻¹)′ = 6·(−1)x⁻² = −6x².
y⁽⁶⁾ = (−6x⁻²)′ = −6·(−2)x⁻³ = 12x³.
y⁽⁷⁾ = (12x⁻³)′ = 12·(−3)x⁻⁴ = −36x⁴.
Шаг 6. Выводим формулу. Начиная с y⁗ = 6x⁻¹, чтобы получить y⁽ⁿ⁾, надо продифференцировать ещё (n−4) раз. Каждый раз показатель падает на 1 и вылезает множитель. После (n−4) дифференцирований 6x⁻¹:
y⁽ⁿ⁾ = 6·(−1)(−2)(−3)…(−(n−4))·x−1−(n−4)
Разбираем множители: чисел в произведении (n−4) штук, их модули дают 1·2·3·…·(n−4) = (n−4)!, а минусов (n−4) штук ⟹ знак (−1)n−4 = (−1)ⁿ. Показатель: −1−(n−4) = −(n−3).
y⁽ⁿ⁾ = (−1)n·6·(n − 4)!xn−3,   n ≥ 4
Ответ: y′ = 3x²ln5x + x²;  y″ = 6x·ln5x + 5x;  y‴ = 6 ln5x + 11;  а при n ≥ 4:  y⁽ⁿ⁾ = (−1)ⁿ·6·(n−4)!/xn−3.

№1. Исследовать на непрерывность

Дано

Решение по шагам
Шаг 1. Где искать разрывы. Два подозрительных места: (а) x = 1 — внутри первой ветви знаменатель 1/(x−1) обращается в ноль; (б) x = 2 — стык двух ветвей.
Шаг 2. Точка x = 1. Смотрим односторонние пределы первой ветви e1/(x−1):
Слева (x→1−0): x−1 → 0⁻, 1/(x−1) → −∞,  e−∞ = 0.
Справа (x→1+0): x−1 → 0⁺, 1/(x−1) → +∞,  e+∞ = +∞.
Один предел конечен (0), другой бесконечен ⟹ разрыв 2-го рода в x = 1.
Шаг 3. Точка x = 2. Слева работает ветвь e1/(x−1), справа — ветвь x²−1.
Слева (x→2−0): e1/(2−1) = e1 = e ≈ 2,718.  Значение f(2) = e1/(2−1) = e (т.к. x ≤ 2 — первая ветвь).
Справа (x→2+0): x² − 1 → 2² − 1 = 3.
Пределы конечны, но e ≠ 3 ⟹ разрыв 1-го рода (скачок), величина скачка 3 − e ≈ 0,282.
x=1 — бесконечный разрыв (справа уходит в +∞), x=2 — конечный скачок на 3−e.
Ответ: x = 1 — разрыв 2-го рода; x = 2 — разрыв 1-го рода (скачок 3 − e); в остальных точках непрерывна.
Проверка: (1) в x=1 справа e1/(x−1) растёт неограниченно — бесконечность подтверждена, слева 0 — верно II род. (2) В x=2 оба предела конечны (e и 3), различны — верно I род; значение f(2)=e совпадает с левым пределом (функция «непрерывна слева»). Численно слева ≈2,718, справа =3 — скачок ≈0,282.

№6. Производная неявной функции

Дано

Шаг 2. Уравнение: 4x³ + 4y³·y′ = 2y + 2x·y′.
Шаг 3. Собираем y′ слева, остальное справа: 4y³·y′ − 2x·y′ = 2y − 4x³.

Шаг 5. Делим (сокращаем на 2):
y′ = 2y − 4x³4y³ − 2x = y − 2x³2y³ − x

Проверка: (1) каждое y дало множитель y′ — верно; 2xy раскрыто по правилу произведения. (2) После сбора y′ слева, остальных членов справа — вынос y′ в скобку корректен. (3) Сокращение на 2 в числителе и знаменателе даёт красивый ответ, выраженный через x и y.

№9. Общая формула n-й производной

Дано

Решение по шагам
Идея: считаем производные и ловим закономерность. Удобно использовать, что −sin α = cos(α + π/2), т.е. каждое дифференцирование «добавляет π/2» в аргумент и множитель k.
Шаг 1. y′ = (cos kx)′ = −k·sin kx. Запишем через косинус: −sin kx = cos(kx + π/2) ⟹ y′ = k·cos(kx + π/2).
Шаг 2. y″ = (−k sin kx)′ = −k²·cos kx = k²·cos(kx + π) = k²·cos(kx + 2·π/2).
Шаг 3. y‴ = (−k² cos kx)′ = k³·sin kx = k³·cos(kx + 3·π/2).
Шаг 4. Закономерность: каждый раз появляется ещё один множитель k и ещё одно слагаемое π/2 в аргументе.
y⁽ⁿ⁾ = kⁿ·cos( kx + n·π2 )
Ответ: y⁽ⁿ⁾ = kⁿ·cos(kx + nπ/2).
Проверка: n=1: k·cos(kx+π/2) = k·(−sin kx) = −k sin kx = y′ ✓. n=2: k²cos(kx+π) = −k²cos kx = y″ ✓. n=4: k⁴cos(kx+2π) = k⁴cos kx — и правда четвёртая производная возвращает косинус с k⁴ ✓.
