Окрестность точки

Интуиция

Окрестность точки a — это «зона вокруг неё», маленький кусочек прямой, внутри которого сидит сама точка. Понятие нужно, чтобы аккуратно сказать словосочетание «x подходит близко к a».

Определения

Окрестность точки a — любой открытый интервал, содержащий a.

δ-окрестность — симметричный интервал радиуса δ вокруг a:

Uδ(a) = (a − δ,   a + δ)

Например, δ = 0,01, a = 1:   Uδ(1) = (0,99;  1,01).

Проколотая δ-окрестность — та же, но без самой точки a:

U̇δ(a) = (a − δ,  a) ∪ (a,  a + δ)
Зачем «проколотая»? В пределе нас интересует, как ведёт себя функция рядом с точкой, а не в самой точке. Поэтому саму точку a из рассмотрения выкалывают — функция в ней может быть даже не определена (вспомни «дырку» на графике).

Интерактив: δ-окрестность на числовой прямой

Предел последовательности

Интуиция

Последовательность a1, a2, a3, … стремится к числу L, если её члены с ростом номера скапливаются возле L и в итоге застревают сколь угодно близко к нему.

Определение (ε–N)
∀ ε > 0   ∃ N :   ∀ n > N   ⇒   |an − L| < ε

ε задаёт горизонтальную полосу шириной 2ε вокруг L. «Предел равен L» означает: какой бы узкой ни была полоса, начиная с некоторого номера N все точки лежат внутри неё.

Интерактив: ε-полоса вокруг предела

an = 1 + (−1)nn → L = 1. Двигай ε и смотри, с какого N все точки внутри полосы.

Предел функции: определение подробно

Частая путаница

Кажется, что в определении одно маленькое число. На самом деле их два, и они разные: близость x к точке a измеряют через δ, а близость f(x) к A — через ε. Одной буквой их писать нельзя — сначала задают ε, а под него подбирают δ.

Определение по Коши (ε–δ)

Число A называется пределом функции f при x → a, если для любого ε > 0 найдётся δ > 0 такое, что как только 0 < |x − a| < δ, выполняется |f(x) − A| < ε.

∀ ε > 0   ∃ δ > 0 :   0 < |x − a| < δ   ⇒   |f(x) − A| < ε

Как это читать словами

  1. ε — это «вызов»: насколько близко к A мы хотим оказаться. Его задаёт «противник», и он может быть сколь угодно маленьким.
  2. δ — это «ответ»: насколько близко к a должен подойти x, чтобы гарантировать попадание в ε-полосу. Мы обязаны найти такое δ под каждый ε.
  3. Порядок важен: сначала дают ε, потом ищут δ. Если под любой ε удаётся подобрать свой δ — предел равен A.
  4. Запись 0 < |x − a| означает «x близко к a, но не равен a» — саму точку выкалываем (значение f(a) на предел не влияет).

Одно и то же определение — разные записи

ФормаЗапись
Через модули (Коши)0 < |x − a| < δ ⇒ |f(x) − A| < ε

Определения Коши и Гейне эквивалентны — это одно и то же понятие предела, просто «на языке ε–δ» и «на языке последовательностей». В разных учебниках встречаются оба; иногда вместо δ пишут другую букву, но смысл тот же.

Разновидности предела

  • Односторонние. Предел слева (x → a−) и справа (x → a+). Двусторонний предел существует ⟺ левый и правый равны.
  • На бесконечности. limx→+∞ f(x) = A:  ∀ ε > 0 ∃ M : x > M ⇒ |f(x) − A| < ε.
  • Бесконечный предел. f(x) → ∞ при x → a:  ∀ E > 0 ∃ δ : 0 < |x − a| < δ ⇒ |f(x)| > E.

Интерактив: ε–δ на графике

Золотая горизонтальная полоса — это ε (высота меряется по оси y вокруг A). Синяя вертикальная полоса — это δ (ширина меряется по оси x вокруг a). Чем у́же ε, тем у́же δ.

Предел по Гейне — «язык тропинок»

Два языка — одно и то же

Есть два определения предела функции, и оба про одно. Разница — как именно мы «подходим» к точке a.

  • По Коши (ε–δ) — «язык коридоров»: под любой узкий коридор ε вокруг A находится коридор δ вокруг a. Проверяем все x сразу.
  • По Гейне (в лекции — «по Чайке») — «язык тропинок»: по любой последовательности точек xn → a (xn ≠ a) значения f(xn) стремятся к A. Проверяем, подходя к a по всевозможным «тропинкам».
Определение по Гейне

Число A — предел функции f в точке a, если для любой последовательности xn → a (xn ≠ a) соответствующая последовательность значений f(xn) → A.

Эквивалентность

Определения по Коши и по Гейне равносильны — задают один и тот же предел. Это теорема (доказывается в обе стороны). Поэтому можно пользоваться любым, смотря что удобнее.

Пример на числах — как считать предел по Гейне

Пусть f(x) = 2x + 1, точка a = 1. Возьмём «тропинку» xn = 1 + 1n — она стремится к 1. Тогда f(xn) = 2(1 + 1n) + 1 = 3 + 2n. Посчитаем значения:

Зачем нужен именно Гейне

Им удобно доказывать, что предела НЕТ: достаточно найти две тропинки xn → a, по которым f(xn) идёт к разным числам. Раз по разным тропинкам разные итоги — общего предела быть не может.

Интерактив: тропинки к пределу

Точки xn подбираются к a, а точки f(xn) — к пределу (слева на оси y). Переключи режим и увеличивай n.

Как работает определение — разбор на примере

Определение как игра

Определение предела удобно понимать как игру двух игроков. Противник называет ε — маленькую «трубу» вокруг числа A: «докажи, что можешь загнать значения функции сюда». Ты отвечаешь: находишь δ — насколько близко к точке a нужно взять x, чтобы значение f(x) точно попало в эту трубу. Если на любой ε у тебя есть ответ δ — значит A действительно предел.

Пример: f(x) = 2x + 1,   x → 1

Подставим точку: f(1) = 2·1 + 1 = 3. Проверим по определению, что предел A = 3. Возьмём произвольное ε > 0 и попробуем найти δ.

Вывод δ из ε

Мы хотим, чтобы выполнялось |f(x) − 3| < ε. Распишем левую часть:

|f(x) − 3| = |(2x + 1) − 3| = |2x − 2| = 2·|x − 1|

Значит условие |f(x) − 3| < ε превращается в:

2·|x − 1| < ε   ⟺   |x − 1| < ε2

Вот и ответ: достаточно взять  δ = ε2.  Тогда как только 0 < |x − 1| < δ, автоматически |f(x) − 3| < ε.

Почему это доказывает, что A = 3 — предел? Мы нашли рабочую δ для любого ε (просто δ = ε/2 — какое ε ни дай, ответ есть). А это ровно то, что требует определение: ∀ε ∃δ. Следовательно, по определению предел равен 3. ∎

Про «такую» δ на графике. δ — это не магическое число: это половина ширины окошка по x, при которой кусок графика над окошком целиком помещается в ε-полосу по y. Для прямой δ = ε/2; для кривой (например x²) δ считается иначе, но смысл тот же — см. интерактив в разделе «Определение предела функции».

Интерактив: почему предел именно A = 3?

Двигай ε (труба вокруг проверяемого A) и сам проверяемый A. Смотри, находится ли δ. Зелёная точка — пример x внутри δ: её значение f(x) попадает в ε-полосу.

Почему не другое число

Поставь A = 3,5 и уменьшай ε. Пока ε > 0,5 труба ещё «дотягивается» до тройки, и δ формально есть. Но как только ε станет меньше 0,5 = |3 − 3,5|, полоса вокруг 3,5 перестаёт накрывать значение 3, к которому функция реально прижимается у x = 1 — и никакая δ не спасёт: точки рядом с a вылетают из ε-полосы. Значит 3,5 пределом быть не может. Пройти проверку на каждом ε способно только одно число — истинный предел 3.

Разновидности предела функции

Односторонние пределы

Справа (x → a+0): для ∀ε>0 ∃δ>0, что при 0 < x − a < δ выполнено |f(x) − A₁| < ε. Обозначают limx→a+0 f(x). Слева (x → a−0) — аналогично при −δ < x − a < 0.

Связь с обычным пределом

Двусторонний предел существует ⟺ левый и правый равны: limx→a f(x) = A ⟺ limx→a−0 = limx→a+0 = A. Если односторонние пределы разные — предела в точке нет (например, у ступеньки).

Предел на бесконечности

limx→+∞ f(x) = A: для ∀ε>0 ∃M, что при x > M выполнено |f(x) − A| < ε.

Бесконечный предел

f(x) → ∞ при x → a: для ∀E>0 ∃δ>0, что при 0 < |x − a| < δ выполнено |f(x)| > E.

Неопределённости

Что это такое

Самый первый приём — просто подставить точку в функцию. Но иногда получается «странное» выражение вроде 0/0 или ∞/∞, из которого ответ не виден. Это и есть неопределённость: не ответ, а сигнал «нужно преобразовать выражение».

Семь видов неопределённостей

00  ·  ∞∞  ·  ∞ − ∞  ·  0 · ∞  ·  1∞  ·  00  ·  ∞0

Раскрыть неопределённость — значит преобразовать выражение так, чтобы подстановка дала конкретное число (или ∞).

Как приходить к ответу без Лопиталя

Лопиталь — мощный, но на первых занятиях его ещё «нельзя»: важно понять механику. Ниже — приёмы, которые заменяют его и объясняют, почему получается именно такой ответ.

1. Прямая подстановка

Если функция непрерывна в точке и неопределённости нет — просто подставь.

limx→2 (x² + 1) = 2² + 1 = 5

2. Неопределённость 0/0 с многочленами → разложить и сократить

Ноль в числителе и знаменателе означает общий множитель (x − a). Раскладываем и сокращаем его.

limx→3 x² − 9x − 3 = lim (x − 3)(x + 3)x − 3 = lim (x + 3) = 6

3. Неопределённость 0/0 с корнями → домножить на сопряжённое

Домножаем числитель и знаменатель на сопряжённое к корню, чтобы «убрать» корень по формуле (√u − √v)(√u + √v) = u − v.

limx→0 √(1 + x) − 1x = lim xx(√(1 + x) + 1) = lim 1√(1 + x) + 1 = 12

4. Неопределённость ∞/∞ (рациональные) → делить на старшую степень

Делим числитель и знаменатель на x в старшей степени. Правило по степеням: числитель степени p, знаменатель степени q:

  • p < q → предел 0;
  • p = q → отношение старших коэффициентов;
  • p > q → предел ∞.
limx→∞ 3x² + 1x² + x = lim 3 + 1/x²1 + 1/x = 3

5. Неопределённость ∞ − ∞ → общий знаменатель или сопряжённое

limx→+∞ (√(x² + x) − x) = lim x√(x² + x) + x = lim 1√(1 + 1/x) + 1 = 12

6. Тригонометрическая 0/0 → первый замечательный предел

limx→0 sin 5xx = lim 5 · sin 5x5x = 5 · 1 = 5

7. Степень вида 1∞ → второй замечательный предел

limx→∞ (1 + 1x)2x = [ (1 + 1x)x ]2 = e²

8. Эквивалентные бесконечно малые — то, что ты делаешь «в уме»

При x → 0 малые функции можно заменять на эквивалентные (см. таблицу в разделе «Замечательные пределы»). Это и есть быстрый способ вместо Лопиталя.

limx→0 ln(1 + x)sin x = [ln(1+x) ~ x,  sin x ~ x] = lim xx = 1
Осторожно

Эквивалентные бесконечно малые можно подставлять только в множителях (в произведении и частном). В сумме/разности так делать нельзя — можно потерять главный член и получить неверный ответ.

Замечательные пределы

Первый замечательный предел

limx→0  sin xx = 1

Геометрически (единичная окружность): при малом угле x выполнено sin x < x < tg x. Разделив на sin x и «сжав» неравенство, получаем, что отношение sin xx зажато между 1 и cos x → 1.

Следствия (при x → 0)

  • tg xx → 1
  • 1 − cos xx² → 12
  • arcsin xx → 1,   arctg xx → 1

Второй замечательный предел

limx→∞ (1 + 1x)x = e  ≈  2,71828…

Эквивалентная запись через x → 0:   limx→0 (1 + x)1/x = e. Работает для неопределённости 1∞.

Следствия (при x → 0)

  • ln(1 + x)x → 1
  • ex − 1x → 1
  • ax − 1x → ln a
  • (1 + x)μ − 1x → μ

Бесконечно малые и порядки малости

Бесконечно малая функция (БМФ)

Функция α(x) называется бесконечно малой при x → a, если limx→a α(x) = 0. (Например, sin x, 1 − cos x, x² при x → 0.)

Зачем сравнивать — на числах

Разные БМФ стремятся к нулю с разной скоростью. Подставим x = 0,1:

x = 0,1;   x² = 0,01;   x³ = 0,001.  Каждая следующая степень в 10 раз меньше.

Говорят: x² высшего порядка малости, чем x («мельче»), а x³ — ещё мельче. Проверка через предел: x²x = x → 0, значит x² мельче x.

Как найти порядок малости (относительно x)

Порядок малости α относительно x — это та степень k, при которой предел αxk становится конечным и не нулём. Ищем k перебором: пока получается 0 — степень мала (α мельче), берём k больше.

Разбор: α = 1 − cos x — почему порядок 2

Из таблицы: 1 − cos x у нуля ведёт себя как x²2 (откуда x²: это следствие первого замечательного предела). Пробуем k:

k = 1:  lim 1 − cos xx = lim x²/2x = lim x2 = 0. Ноль — значит 1 − cos x мельче, чем x; k = 1 мало.

k = 2:  lim 1 − cos xx² = lim x²/2x² = 12 ≠ 0. Конечное ненулевое — попали.

Деление на x даёт 0 (мало), деление на x² даёт 1/2 (в самый раз) ⟹ порядок малости = 2.

Задача. Найди порядок малости α = tg x − sin x относительно x.

Решение
Известно, что tg x − sin x ведёт себя как x³2. Перебираем k:
k = 1: x³/2x = x²2 → 0 (мало).   k = 2: x³/2x² = x2 → 0 (ещё мало).
k = 3: x³/2x³ = 12 ≠ 0 — попали ⟹ порядок 3 (очень «мелкая»).

Задача. Порядок малости α = √(1 + x) − 1.

Решение
√(1 + x) − 1 ~ x2. k = 1: x/2x = 12 ≠ 0 — сразу попали ⟹ порядок 1.

Правило простое: делим α на x, x², x³… — первая степень, где получилось не ноль, и есть порядок малости. А метод эквивалентностей — это замена α на «x^(порядок)·коэффициент», что сохраняет предел отношения.

Реальные пределы через порядки малости

Тут порядки малости работают «вживую»: сравниваем, какого порядка числитель и знаменатель, и сокращаем.

1. limx→0 e2x − 1sin 3x

Решение
Числитель e2x − 1 ~ 2x (порядок 1). Знаменатель sin 3x ~ 3x (порядок 1) — одного порядка.
2x3x = 23.

2. limx→0 1 − cos xx·tg x

Решение
Числитель 1 − cos x ~ x²2 (порядок 2). Знаменатель x·tg x ~ x·x = x² (порядок 2) — тоже порядка 2.
x²/2x² = 12.

Символы Ландау

Зачем они

Символы Ландау — короткий язык, чтобы сказать «эта функция у нуля мельче той» или «они одного масштаба», не выписывая каждый раз пределы. Это сжатая запись сравнения бесконечно малых.

o — «о-маленькое»

Если α(x) — б.м.ф. высшего порядка по сравнению с β(x) при x → a, то есть limx→a α(x)β(x) = 0, пишут:

α(x) = o(β(x))

Читается «α есть о-маленькое от β»: α убывает быстрее, чем β. Пример: x² = o(x) при x → 0, ведь x²/x = x → 0.

O — «O-большое»

Если α(x) и β(x) одного порядка, то есть limx→a α(x)β(x) = c ≠ 0, пишут:

α(x) = O(β(x)),   β(x) = O(α(x))

Это значит «α того же масштаба, что β». Пример: sin x = O(x) и x = O(sin x) при x → 0 (отношение → 1 ≠ 0).

Свойства «о-маленького»

o(f) = o(c·f),  c ≠ 0константа масштаб не меняет

Все эти равенства «односторонние»: слева «какая-то мелкая величина такого-то порядка», справа — «мелкая того же порядка». Знак «=» здесь означает «принадлежит классу», а не тождество.

Главная часть функции

Если функцию α(x) можно записать в виде α(x) = β(x) + o(β(x)), то β(x) называют главной частью α(x). Это «основной кусок», а o(β) — мелкая поправка.

Критерий эквивалентности

α(x) ~ β(x) при x → a  ⟺  α(x) = β(x) + o(β(x)). Иначе: «быть эквивалентными» = «отличаться на величину высшего порядка».

Почему (необходимость). Пусть α ~ β, то есть α/β → 1. Тогда α − ββ = αβ − 1 → 1 − 1 = 0 ⟹ α − β = o(β) ⟹ α = β + o(β). Обратно: если α = β + o(β), то α/β = 1 + o(β)/β = 1 + 0 = 1 ⟹ α ~ β.
На примере

sin x = x + o(x),   1 − cos x = x²2 + o(x²),   ex − 1 = x + o(x). Главная часть у каждого — первое слагаемое; именно его и используют как «двойник» в пределах.

Замена эквивалентными: главный рабочий приём

Теорема

Если в пределе отношения (или произведения) бесконечно малых заменить множители на эквивалентные — предел не изменится. Если f ~ f₁ и g ~ g₁, то

limx→a fg = limx→a f₁g₁

(при условии, что правый предел существует).

Осторожно

Заменять эквивалентными можно только в множителях произведения и частного. В сумме и разности так делать нельзя — можно потерять главную часть (например, в tg x − sin x наивная замена обоих на x даст 0, а правильный ответ — порядка x³).

Теоремы о пределах последовательностей

Единственность

Сходящаяся последовательность имеет ровно один предел.

Ограниченность

Всякая сходящаяся последовательность ограничена (обратное неверно: (−1)n ограничена, но предела нет).

Теорема о зажатой («о двух милиционерах»)

Если xn ≤ yn ≤ zn (начиная с некоторого номера) и xn → a, zn → a, то и yn → a.

Как пользоваться

Зажимаем «неудобную» последовательность между двумя простыми с одинаковым пределом. Так, например, доказывают первый замечательный предел.

Арифметика пределов

Если xn → a, yn → b, то: xn ± yn → a ± b;   xn·yn → a·b;   xnyn → ab (при b ≠ 0).

Пример — арифметика в деле

lim 3n² + 2nn² + 1. Делим числитель и знаменатель на n²: 3 + 2/n1 + 1/n².

По арифметике: 2/n → 0 и 1/n² → 0, значит числитель → 3, знаменатель → 1, а их частное → 3.

Монотонные последовательности

Определения

Неубывающая: x1 ≤ x2 ≤ … Невозрастающая: x1 ≥ x2 ≥ … Строгие неравенства дают монотонно возрастающую/убывающую.

Теорема Вейерштрасса

Если неубывающая последовательность ограничена сверху, то она имеет предел (равный её точной верхней грани sup). Аналогично невозрастающая, ограниченная снизу, имеет предел (равный inf).

Показать идею доказательства
Ограниченная сверху последовательность имеет точную верхнюю грань L = sup{xn}.
Для любого ε > 0 число L − ε уже не верхняя грань, поэтому найдётся xN > L − ε. А так как последовательность неубывающая и L — верхняя грань, при всех n > N: L − ε < xn ≤ L < L + ε, то есть |xn − L| < ε. Значит lim xn = L. ∎

Это главный инструмент: чтобы доказать существование предела, часто достаточно показать монотонность + ограниченность (не находя сам предел).

Критерий Коши

Критерий

Последовательность (xn) сходится тогда и только тогда, когда она фундаментальная: для любого ε > 0 найдётся N такое, что для всех n > N и всех p ∈ ℕ выполнено |xn+p − xn| < ε.

Смысл

Члены последовательности с большими номерами становятся сколь угодно близки друг к другу — не нужно заранее знать предел, чтобы доказать сходимость. Удобно, когда предел неизвестен.

Число e

Теорема

Последовательность xn = (1 + 1n)n имеет предел, который обозначают буквой e:

limn→∞ (1 + 1n)n = e ≈ 2,718281…
Как это доказывают

Показывают два факта — и дальше работает теорема Вейерштрасса:

  1. Монотонность: раскрыв (1+1/n)n по биному Ньютона, видно, что каждый следующий член xn+1 имеет и больше слагаемых, и каждое слагаемое больше (множители вида (1 − k/n) растут с ростом n). Значит xn возрастает.
  2. Ограниченность сверху: та же сумма оценивается сверху рядом 1 + 1 + 12! + 13! + … < 3.

Возрастает и ограничена ⟹ по Вейерштрассу предел существует. Его и назвали e.

Отсюда растёт второй замечательный предел: lim (1 + 1/x)x = e (см. главу «Вычисление»).

Непрерывность функции в точке

Интуиция

Функция непрерывна в точке, если её график около этой точки можно нарисовать не отрывая карандаша: нет скачков, дыр и разрывов. Формально — предел в точке совпадает со значением функции.

Определение (через предел)

Пусть x₀ ∈ D(f). Функция f(x) называется непрерывной в точке x₀, если

limx→x₀ f(x) = f(x₀)

То есть: предел существует, значение в точке существует, и они равны.

То же на языке ε–δ

f(x) непрерывна в x₀, если для любого ε > 0 найдётся δ(ε) > 0 такое, что при |x − x₀| < δ выполнено |f(x) − f(x₀)| < ε.

Отличие от «обычного» предела: здесь предельное значение обязано совпасть с f(x₀), а точку x₀ не прокалывают — функция должна быть определена и в самой точке.

Свойства непрерывных функций

  1. Локальная ограниченность. Если f непрерывна в x₀, то она ограничена в некоторой окрестности x₀.
  2. Сохранение неравенства. Если f и g непрерывны в x₀ и f(x) < g(x) в окрестности, то и f(x₀) ≤ g(x₀).
  3. Сохранение знака. Если f непрерывна в x₀ и f(x) > 0 в окрестности, то f(x₀) ≥ 0.
  4. Арифметика. Если f и g непрерывны в x₀, то f + g,  f·g  и  f/g (при g(x₀) ≠ 0) тоже непрерывны в x₀.
  5. Критерий через приращение. f непрерывна в x₀ ⟺ f(x) = f(x₀) + α(x), где α(x) → 0 при x → x₀ (приращение функции бесконечно мало).
  6. Сложная функция. Если t = u(x) непрерывна в x₀, а f(t) непрерывна в t₀ = u(x₀), то f(u(x)) непрерывна в x₀.
Проверка на числах

f(x) = x² + 1 в точке x₀ = 2:  limx→2(x² + 1) = 5,  f(2) = 5.  Совпали ⟹ непрерывна.

g(x) = sin xx в точке x₀ = 0:  limx→0 g = 1, но g(0) не определена ⟹ в точке 0 функция не непрерывна (но разрыв «чинится», см. ниже).

Классификация точек разрыва

Три вида «поломки»

Если в точке x₀ непрерывность нарушена, смотрят на односторонние пределы f(x₀−0) и f(x₀+0) — что с ними происходит.

1. Устранимый разрыв

Односторонние пределы существуют, конечны и равны между собой, но не равны f(x₀) (или f(x₀) не определена). Функцию можно доопределить до непрерывной.

Пример: y = sin x / x в x = 0

limx→0 sin xx = 1 слева и справа, но в x = 0 функция не определена. Чиним, доопределив значением предела:

y = { 1 при x = 0;   sin xx при x ≠ 0 }

Теперь функция непрерывна всюду — «дырку» в графике заполнили одной точкой.

2. Разрыв 1-го рода (скачок)

Односторонние пределы конечны, но не равны между собой:  limx→x₀−0 f ≠ limx→x₀+0 f. Разность значений — «скачок».

Пример: y = sign x в x = 0

sign x = −1 при x < 0;  0 при x = 0;  1 при x > 0.

limx→0−0 sign x = −1,  limx→0+0 sign x = +1. Пределы конечны, но разные ⟹ x = 0 — разрыв 1-го рода, скачок величиной 2.

3. Разрыв 2-го рода

Хотя бы один из односторонних пределов бесконечен либо не существует.

Пример: y = 1/x в x = 0

limx→0−0 1x = −∞,  limx→0+0 1x = +∞. Пределы бесконечны ⟹ x = 0 — разрыв 2-го рода (вертикальная асимптота).

Функции, непрерывные на отрезке

Определение

Функция f(x) непрерывна на интервале, если она непрерывна в каждой точке этого интервала. На отрезке [a, b] добавляют односторонние пределы на концах.

Теорема 1 (Вейерштрасса) — ограниченность

Функция, непрерывная на отрезке [a, b], ограничена на нём: ∃ M > 0, что |f(x)| ≤ M для всех x ∈ [a, b].

Идея (от противного). Если f неограничена, найдётся последовательность xₙ ∈ [a, b] c |f(xₙ)| → ∞. Но из ограниченной последовательности {xₙ} можно выделить сходящуюся подпоследовательность xₙₖ → x₀ ∈ [a, b]; по непрерывности f(xₙₖ) → f(x₀) — конечное число. Противоречие.
Теорема 2 (Вейерштрасса) — достижение экстремумов

Функция, непрерывная на [a, b], достигает на нём своего наибольшего и наименьшего значения: ∃ ξ₁, ξ₂ ∈ [a, b], что f(ξ₁) = max f = M и f(ξ₂) = min f.

Идея (от противного). Если точная верхняя граница M не достигается, то f(x) < M всюду, и функция u(x) = 1/(M − f(x)) непрерывна и положительна, значит (по Т.1) ограничена: u(x) ≤ μ. Тогда f(x) ≤ M − 1/μ < M — но это противоречит тому, что M — точная верхняя граница. Значит M достигается.
Непрерывная кривая на отрезке [a, b] «зажата» между линиями m и M (Т.1 — ограниченность). Самую высокую точку она берёт в ξ₁ (значение M), самую низкую — в ξ₂ (значение m): эти значения достигаются (Т.2).
На числах: f(x) = x² на [−1, 2]

Функция непрерывна. Наибольшее значение M = 4 достигается в ξ₁ = 2 (правый конец), наименьшее m = 0 — в ξ₂ = 0 (внутри отрезка). Ограничена: |f(x)| ≤ 4 для всех x ∈ [−1, 2]. Всё, как обещают теоремы.

Важно: именно отрезок

На открытом интервале теоремы ломаются. Пример: f(x) = 1/x непрерывна на (0, 1), но не ограничена. Пример: f(x) = x на (0, 1) не достигает ни 0, ни 1. Нужны оба конца — замкнутость отрезка.

Промежуточные значения и асимптоты

Теорема 3 (Больцано–Коши)

Если f(x) непрерывна на [a, b] и на концах принимает разные значения f(a) = A, f(b) = B, то для любого C между A и B (A < C < B) найдётся точка c ∈ [a, b], в которой f(c) = C.

По-человечески

Непрерывный график, идя от высоты A до высоты B, проходит через все промежуточные высоты — не может «перепрыгнуть» уровень.

Любой уровень C между A = f(a) и B = f(b) обязательно пересекается графиком — в точке c получаем f(c) = C. «Перескочить» уровень непрерывная кривая не может.
Следствие 1 — теорема о корне

Если на концах значения разных знаков: f(a)·f(b) < 0, то внутри есть корень: ∃ c ∈ [a, b], f(c) = 0.

На числах

f(x) = x³ − x − 1 на [1, 2]: f(1) = −1 < 0, f(2) = 5 > 0. Знаки разные ⟹ есть корень между 1 и 2 (это основа метода половинного деления).

Следствие 2 — сохранение знака

Если f непрерывна в x₀ и f(x₀) ≠ 0, то найдётся окрестность Uδ(x₀), в которой f сохраняет свой знак.
