Матрицы · определители · обратная · ранг · системы

Что такое матрица

Определение

Матрица — прямоугольная таблица чисел. Размер m × n (m строк, n столбцов); элемент aij стоит в i-й строке, j-м столбце. Если m = n — матрица квадратная.

Пример A = 2−10537 — размер 2 × 3; здесь a21 = 5, a13 = 0.

Диагонали и след

Определения

Главная диагональ — из левого верхнего угла в правый нижний, побочная — из правого верхнего в левый нижний. След tr A = a11 + a22 + … + ann.

Пример Для 214056783 след = 2 + 5 + 3 = 10.

Частные виды

Определения

Нулевая — все элементы 0. Диагональная — вне диагонали нули. Скалярная — диагональная с одинаковыми числами. Единичная E — с единицами на диагонали (δij = 1 при i=j, иначе 0). Вектор-строка / вектор-столбец — одна строка / один столбец.

Примеры E = 100010001,   diag(2,−1,5) = 2000−10005.

Треугольные матрицы

Определение

Верхняя треугольная: под диагональю нули (aij = 0 при i > j). Нижняя: нули выше диагонали.

Пример 123045006 — верхняя треугольная.
След определён только для квадратной матрицы, поэтому последний член — ann.

Транспонирование

Определение

Транспонированная AT — строки становятся столбцами: A = (aij)m×n → AT = (aji)n×m.

Пример 123456T = 142536 (2×3 → 3×2).
Размер AT — n×m: строки и столбцы меняются местами.

Симметрические и кососимметрические

Определения

Симметрическая: aij = aji (A = AT). Кососимметрическая: aij = −aji, на диагонали нули.

Примеры симметрическая 123245356; кососимметрическая 02−3−2013−10.

Транспонирование квадратной матрицы = отражение относительно главной диагонали.

Сумма и умножение на число

Определения

Сумма/разность матриц одинакового размера: cij = aij ± bij. Умножение на λ: cij = λ·aij.

Пример 1234 + 0511 = 1745,   3·1204 = 36012.

Свойства

  • A + B = B + A коммутативность;   A + (B + C) = (A + B) + C
  • A + Θ = A;   A + (−A) = Θ;   (α + β)A = αA + βA;   α(A + B) = αA + αB
  • (λA)T = λAT, (A + B)T = AT + BT, (AT)T = A

Произведение матриц

Определение

Am×n · Bn×p = Cm×p, где cij = ∑k aikbkj — сумма произведений i-й строки A на j-й столбец B.

Условие согласованности: число столбцов A = числу строк B.

Почему «строка на столбец»

Матрица — это запись линейной замены переменных. Если (y₁,y₂) выражены через (x₁,x₂) матрицей A, а (z₁,z₂) через (y₁,y₂) матрицей B, то подстановка даёт z₁ = (b₁₁a₁₁ + b₁₂a₂₁)x₁ + … — коэффициент при x₁ и есть «строка B на столбец A». Отсюда и условие согласованности, и некоммутативность (порядок замен важен).

Пример 1234·20 = 1·2+2·03·2+4·0 = 26
Внимание

Обычно AB ≠ BA (полный разбор — в главе «Разборы задач»).

Свойства

  • A(BC) = (AB)C;   A(B + C) = AB + AC;   (A + B)C = AC + BC
  • (A·B)T = BT·AT порядок меняется

Многочлен от матрицы

Определение

A0 = E, A2 = A·A. Если f(x) = a0xn + … + an, то f(A) = a0An + … + an−1A + anE (свободный член умножается на E).

Пример f(x) = 3x² − 4, A = 2103 → f(A) = 3A² − 4E. Полный расчёт — в главе «Разборы задач».

Перестановки и инверсии

Определения

Перестановка — расположение n элементов; всего их n!. Пара образует инверсию, если бо́льший элемент стоит раньше меньшего. Перестановка чётная, если инверсий чётное число.

Пример В [3, 1, 2] инверсии: (3,1) и (3,2) — две ⟹ перестановка чётная.
Транспозиция

Перемена местами двух элементов; всякая транспозиция меняет чётность на противоположную.

Определитель n-го порядка

Определение

Определитель — сумма n! произведений, по одному элементу из каждой строки и столбца; знак «+» для чётной перестановки индексов строк, «−» для нечётной.

det A = ∑ (−1)[инверсии] · ai₁1·ai₂2·…·aiₙn

Обозначения: |A|, det A, Δ.

Определитель 2-го порядка

|a11a12a21a22| = a11a22 − a12a21
Пример |3214| = 3·4 − 2·1 = 10.
||
det = a₁₁·a₂₂ − a₁₂·a₂₁

Определитель 3-го порядка

Правило треугольника (Саррюса): три «прямых» произведения со знаком «+», три «обратных» со знаком «−». Полный разбор 3×3 двумя способами — в главе «Разборы задач».

Что определитель означает геометрически

Главная идея

Определитель 2×2 — ориентированная площадь параллелограмма на строках-векторах; 3×3 — объём параллелепипеда. Отсюда: det = 0 ⟺ строки линейно зависимы.

det abcd = a·d − b·c = площадь параллелограмма на (a,b) и (c,d)

Интерактив: определитель = площадь

Тяни концы векторов-строк. Площадь = |det|. Сделай их коллинеарными — det обнулится.

Свойства

Всё, что верно для строк, верно и для столбцов (т.к. det A = det AT).

  1. Нулевая строка ⇒ det = 0.
  2. Строку умножили на λ ⇒ det умножился на λ.
  3. Поменяли две строки ⇒ det сменил знак.
  4. Две одинаковые строки ⇒ det = 0.
  5. Строка — линейная комбинация других ⇒ det = 0 (в частности, пропорциональные строки).
  6. Прибавили к строке комбинацию других строк ⇒ det не изменился.
  7. det A = det AT.
  8. Строка — сумма двух слагаемых ⇒ det раскладывается в сумму двух определителей.
Почему — через площадь
  • 1: нулевой вектор → вырождение → 0.   2: растянули сторону в λ раз → площадь в λ раз.
  • 3: перестановка меняет ориентацию → знак.   4,5: зависимые векторы на прямой → площадь 0.
  • 6: «скашивание» вдоль стороны не меняет площадь.

Миноры и алгебраические дополнения

Определения

Минор Mik элемента aik — определитель (n−1)-го порядка, полученный вычёркиванием i-й строки и k-го столбца. Алгебраическое дополнение Aik = (−1)i+k·Mik.

Пример Для a11a12a13a21a22a23a31a32a33 минор M32 (вычёркиваем 3-ю строку и 2-й столбец) = a11a13a21a23, A32 = (−1)5M32 = −M32.
Почему знак (−1)^(i+k)

Шахматный порядок плюсов и минусов: +−+−+−+−+ — чтобы разложение согласовалось с чётностью перестановок.

Разложение определителя по строке

Определение

При n = 1: |A| = a11. При n ≥ 2 раскладываем по любой i-й строке:

|A| = ai1Ai1 + ai2Ai2 + … + ainAin,   Aij = (−1)i+jMij
Зачем

Способ считать определитель любого порядка: n×n сводится к нескольким (n−1)×(n−1). Выгодно раскладывать по строке/столбцу с нулями. Полный пример 3×3 — в «Разборах задач».

Приведение к треугольному виду

Элементарные преобразования

1-й тип: перестановка двух строк/столбцов. 2-й тип: прибавление к строке другой строки ×k.

Влияние на определитель

1-й тип меняет знак; 2-й тип не меняет определитель.

Теорема

Любой определитель приводится элементарными преобразованиями к треугольному виду, а он равен произведению диагонали:

Δтреуг = a11·a22·…·ann

Обнуляем всё под диагональю (метод Гаусса), следя за знаком при перестановках. Разбор 4×4 — в «Разборах задач».

Определитель Вандермонда

Δ(a1, …, an) = |11…1a1a2…ana1²a2²…an²a1n−1a2n−1…ann−1| = ∏i>j(ai − aj)

Равен нулю ⟺ среди ai есть два одинаковых.

Определитель произведения

Теорема
det(A·B) = det A · det B

Следствие: если det A ≠ 0, то det A⁻¹ = 1 / det A (из det(A·A⁻¹) = det E = 1).

Основные определения

Определения

Невырожденная матрица — det A ≠ 0. Обратная A⁻¹ — матрица того же порядка, для которой A·A⁻¹ = A⁻¹·A = E.

Аналогия с числами

У числа a ≠ 0 есть обратное 1/a. У матриц роль «обратного числа» играет A⁻¹ — она отменяет действие A. Деления матриц нет; обратная есть только у невырожденной (аналог a ≠ 0 — это det A ≠ 0).

Теоремы

Единственность: если обратная есть, она единственна (B = B·E = B(AC) = (BA)C = E·C = C). Критерий: A⁻¹ существует ⟺ det A ≠ 0 (из A·A⁻¹ = E берём det: det A · det A⁻¹ = 1).

Союзная матрица и формула

Определение

Союзная A* — матрица из алгебраических дополнений, транспонированная. Тогда

A⁻¹ = 1|A|·A*
Почему работает

Строка на свои дополнения = |A| (разложение по строке), на чужие = 0 (это определитель с двумя одинаковыми строками). Значит A·A* = |A|·E, откуда A·(A*/|A|) = E.

Алгоритм нахождения A⁻¹

  1. Проверить |A| ≠ 0.
  2. Найти все алгебраические дополнения Aij = (−1)i+jMij.
  3. Составить союзную A* (матрицу дополнений транспонировать).
  4. Умножить на 1/|A|.

Полный пример обратной 3×3 и 2×2 — в главе «Разборы задач».

Свойства

  • (A⁻¹)⁻¹ = A;   (λA)⁻¹ = 1λ·A⁻¹  (λ ≠ 0);   (AT)⁻¹ = (A⁻¹)T;   |A⁻¹| = 1|A|
  • (A·B)⁻¹ = B⁻¹·A⁻¹ порядок меняется
Верно (A·B)⁻¹ = B⁻¹·A⁻¹ (порядок множителей меняется, как при транспонировании).

Матричные уравнения

Определение

Уравнение с неизвестной матрицей X. Два типа (|A| ≠ 0):

Тип 1: A·X = B  ·  Тип 2: Y·A = B
Аналогия

Скалярное a·x = b решают как x = a⁻¹·b. У матриц так же, но важна сторона: домножать на A⁻¹ надо с той стороны, где стоит A.

Решения

Тип 1: домножаем слева ⟹ X = A⁻¹·B.   Тип 2: домножаем справа ⟹ Y = B·A⁻¹.

Сторона умножения

Умножение не коммутативно — перепутаешь сторону, получишь неверный ответ. Примеры обоих типов — в «Разборах задач».

Системы линейных уравнений (СЛАУ)

Матричная форма

Систему из n уравнений с n неизвестными записывают как A·X = B, где A — матрица коэффициентов, X — столбец неизвестных, B — столбец свободных членов.

A·X = B  ⟹  если |A| ≠ 0, то X = A⁻¹·B (единственное решение)

Правило Крамера

Теорема

Если Δ = det A ≠ 0, система имеет единственное решение:

xi = ΔiΔ,   i = 1…n

где Δi — определитель, полученный из Δ заменой i-го столбца на столбец свободных членов B.

Показать идею доказательства
Из A·X = B при |A| ≠ 0: X = A⁻¹B = (1/|A|)·A*·B. Расписав произведение A*·B по строкам, i-я координата даёт a1ib1+…+anibn — это в точности разложение определителя Δi по столбцу B. Значит xi = Δi/Δ. ∎

Разобранный пример

Решить систему:   2x + y = 5,   x + 3y = 10.

Δ = |2113| = 6 − 1 = 5 ≠ 0 — решение единственно.
Δx — заменяем 1-й столбец на (5, 10): |51103| = 15 − 10 = 5 ⟹ x = 5/5 = 1.
Δy — заменяем 2-й столбец на (5, 10): |25110| = 20 − 5 = 15 ⟹ y = 15/5 = 3.
Проверка: 2·1 + 3 = 5 ✓,   1 + 3·3 = 10 ✓.

Однородные системы (B = 0)

Свойство

Однородная система A·X = 0 всегда имеет нулевое решение. Если det A ≠ 0 — оно единственное (только нулевое). Если det A = 0 — есть и ненулевые решения.

Случай неквадратных систем и det A = 0 разбирается через ранг (глава «Ранг»).

Когда у системы вообще есть решение?

Три исхода

У системы бывает три варианта: решений нет (уравнения противоречат друг другу — из них выводится неверное равенство вроде 0 = 2), ровно одно решение, или бесконечно много. Какой именно — показывает сравнение двух рангов.

Обозначения: A — матрица коэффициентов (числа при неизвестных). B — столбец правых частей. (A | B) — «расширенная» матрица: к A дописан столбец B. rang A и rang(A|B) — их ранги. n — число неизвестных.
Теорема Кронекера–Капелли

Система имеет решение (совместна) тогда и только тогда, когда rang A = rang(A | B). А дальше:

  • rang A ≠ rang(A|B) ⟹ решений нет (несовместна);
  • rang A = rang(A|B) = n ⟹ одно решение;
  • rang A = rang(A|B) = r < n ⟹ бесконечно много решений (свободных переменных n − r).
Пример 1 — решения есть

x + y = 3,   2x + 2y = 6. Расширенная: (A|B) = 113226. Вся вторая строка = 2·первой, поэтому rang A = 1 и rang(A|B) = 1 — равны. Система совместна; так как r = 1 < n = 2 — решений бесконечно много (второе уравнение ничего нового не даёт).

Пример 2 — решений нет

x + y = 3,   2x + 2y = 5. Расширенная: (A|B) = 113225. В матрице A строки пропорциональны (rang A = 1), а в (A|B) из-за столбца (3, 5) — уже нет (rang(A|B) = 2). Ранги разные ⟹ решений нет.

Видно и напрямую: вычтем из 2-го уравнения удвоенное 1-е: (2x + 2y) − 2(x + y) = 5 − 2·3 ⟹ 0 = −1 — противоречие. Решений нет.

Случай r = n (Крамер)

Если ранг равен числу неизвестных — квадратная матрица при неизвестных невырождена, и система решается по правилу Крамера: xi = Δi/Δ. Решение единственное. Полные разборы 3×3 и 4×4 — в главе «Разборы задач».

Случай r < n (главные и свободные)

Что делаем

Неизвестных больше, чем «реальных» уравнений (r). Часть неизвестных берём главными (их r — те, при которых стоит ненулевой минор), а остальные (n − r) объявляем свободными — им можно давать любые значения. Главные выражаем через свободные. Ответ — общее решение с параметрами.

Разобранный пример

Решим систему:   x + 2y + z = 4,   2x + y − z = 5.

Шаг 0. Что за ситуация. Уравнений 2, а неизвестных 3 (x, y, z). Неизвестных больше, чем уравнений — одного решения быть не может, их бесконечно много. Значит одну переменную сделаем «свободной» (дадим ей любое значение), а две — «главными» (они подстроятся под свободную).
Шаг 1. Выбираем главные и свободную. Главными берём те неизвестные, при которых получается ненулевой определитель. Попробуем x и y — их коэффициенты в двух уравнениях (1, 2 и 2, 1) дают:
  1221 = 1·1 − 2·2 = −3 ≠ 0.
Определитель не ноль ⟹ берём x, y главными, а оставшуюся z — свободной. (Главных должно быть r = 2, свободных n − r = 1.)
Шаг 2. Свободную z — в правую часть. Чтобы относительно x, y осталась обычная система 2×2, переносим всё с z вправо:
  из 1-го:  x + 2y + z = 4  →  x + 2y = 4 − z;
  из 2-го:  2x + y − z = 5  →  2x + y = 5 + z.
Теперь z сидит в правой части как параметр — число, которое мы пока не фиксируем.
Шаг 3. Главный определитель Δ. Из коэффициентов при x, y (тот же, что в шаге 1):
  Δ = 1221 = 1·1 − 2·2 = −3.
Шаг 4. Находим x. В определителе Δ заменяем 1-й столбец (коэффициенты при x) на правые части (4−z и 5+z):
  Δx = 4−z25+z1 = (4−z)·1 − 2·(5+z) = 4 − z − 10 − 2z = −6 − 3z.
  x = ΔxΔ = −6 − 3z−3 = 2 + z.
Шаг 5. Находим y. Теперь заменяем 2-й столбец (при y) на правые части:
  Δy = 14−z25+z = 1·(5+z) − 2·(4−z) = 5 + z − 8 + 2z = −3 + 3z.
  y = ΔyΔ = −3 + 3z−3 = 1 − z.
Шаг 6. Записываем общее решение. Получили x = 2 + z, y = 1 − z, а z осталась свободной (z = z). Итог:
  (x, y, z) = (2 + z,   1 − z,   z),   где z — любое число.
Шаг 7. Откуда берутся конкретные решения. Подставляем в формулу разные z — и каждый раз получаем готовое решение. Их бесконечно много:
  z = 0  →  (2, 1, 0);    z = 1  →  (3, 0, 1);    z = −1  →  (1, 2, −1).
Шаг 8. Проверка. Берём (2, 1, 0): 2 + 2·1 + 0 = 4 ✓,   2·2 + 1 − 0 = 5 ✓. Берём (3, 0, 1): 3 + 0 + 1 = 4 ✓,   2·3 + 0 − 1 = 5 ✓. Оба подходят — значит формула верна.

Что значит «зависимы» — на числах

Идея

Строки зависимы, если одна из них «повторяет» другие — выражается через них. Тогда она не несёт новой информации. Если же ни одна не выражается через другие — строки независимы. Сначала два примера с числами, потом аккуратные определения.

Пример 1 — ЗАВИСИМЫЕ

Строки a = (1, 2) и b = (2, 4). Видно, что b = 2·a. Проверим, что их комбинация может обнулиться не тривиально:

2·a − 1·b = 2·(1, 2) − 1·(2, 4) = (2, 4) − (2, 4) = (0, 0).

Коэффициенты (2, −1) не нулевые, а сумма = 0 ⟹ строки линейно зависимы.

Пример 2 — НЕЗАВИСИМЫЕ

Строки a = (1, 2) и b = (3, 1). Попробуем подобрать α, β так, чтобы α·a + β·b = (0, 0):

α·(1, 2) + β·(3, 1) = (α + 3β,   2α + β) = (0, 0) ⟹   α + 3β = 0  и  2α + β = 0.

Из первого: α = −3β. Подставляем во второе: 2·(−3β) + β = −5β = 0 ⟹ β = 0, тогда и α = 0.

Обнулить можно только нулевыми коэффициентами ⟹ строки линейно независимы.

Теперь строгие определения

Линейная комбинация

Для строк a1, …, an выражение α1a1 + α2a2 + … + αnan (αi — числа) — их линейная комбинация. В примерах это было «2a − 1b» и «αa + βb».

Независимость и зависимость

Линейно независимы (ЛНЗ): равенство α1a1 + … + αnan = 0 возможно только при всех αi = 0 (как в примере 2). Такая «нулевая» комбинация — тривиальная.

Линейно зависимы (ЛЗ): нашлись коэффициенты, не все нулевые, с нулевой суммой (как в примере 1 — коэффициенты 2 и −1). Такая комбинация — нетривиальная.

Если среди строк есть нулевая строка (0, 0, …) — система всегда зависима: берём её с коэффициентом 1, остальные с нулями, сумма = 0 при ненулевом коэффициенте.
Теорема

Строки линейно зависимы тогда и только тогда, когда одна из них выражается через остальные (является их линейной комбинацией).

Пример к теореме — три строки

Матрица A = 321220−110451, строки: e1 = (3,2,1,2), e2 = (2,0,−1,1), e3 = (0,4,5,1).

2·e1 − 3·e2 = (6,4,2,4) − (6,0,−3,3) = (0, 4, 5, 1) = e3.

Значит e3 = 2e1 − 3e2 — третья строка выражается через первые две ⟹ строки зависимы. Независимых строк всего две — поэтому у матрицы ранг = 2.

Что такое ранг

Интуиция

Ранг показывает, сколько в матрице «независимых» строк (или столбцов) — сколько реальной информации в ней после отбрасывания строк, которые выражаются через другие. От него зависит число решений системы.

Будем всё показывать на одной матрице. Возьмём 213011235 — заметим, что 3-я строка = 1-я + 2·(2-я): (2, 3, 5) = (2, 1, 3) + 2·(0, 1, 1). То есть одна строка «лишняя».

Определение 1 — ранг

Ранг матрицы — наивысший порядок её минора, отличного от нуля. (Минор — это определитель квадратного «кусочка» матрицы.) Обозначение: rang A, rg A, r.

Что значит «минор порядка r»

Минор порядка 1 — просто один элемент, например a11 = 2.

Минор порядка 2 — определитель из любых 2 строк и 2 столбцов. Например, строки 1,2 и столбцы 1,3: 2301 = 2·1 − 3·0 = 2.

Минор порядка 3 — весь определитель (строки и столбцы 1,2,3): он равен 0 (третья строка зависима).

Определение 2 — главный минор

Главный минор — тот, что стоит в левом верхнем углу (строки и столбцы 1…r).

Пример Главный минор порядка 2 нашей матрицы: 2101 = 2·1 − 1·0 = 2 ≠ 0.

Находим ранг нашей матрицы

Есть ненулевой минор порядка 2 (=2), значит ранг ≥ 2.
Единственный минор порядка 3 (весь определитель) = 0. Минора порядка 3, отличного от нуля, нет.
Значит наивысший порядок ненулевого минора = 2 ⟹ ранг = 2 (как и ожидали: две независимые строки, третья лишняя).
Определение 3 — базисный минор

Базисный минор — любой ненулевой минор порядка r (равного рангу). Все миноры бо́льших порядков — нулевые.

Базисный минор — не один

У нас r = 2. Базисным будет, например, 2101 = 2 (строки 1,2, столбцы 1,2).

Но подойдёт и другой — из строк 2,3 и столбцов 2,3: 1135 = 5 − 3 = 2 ≠ 0. Тоже базисный.

Поэтому базисный минор определяется не единственным образом — их может быть несколько.

Правило окаймляющих миноров

Правило

Идём от малых порядков к бо́льшим. Нашли ненулевой минор порядка r — проверяем только те миноры порядка r+1, что окаймляют его (добавляют к нему одну строку и один столбец). Если все окаймляющие миноры порядка r+1 равны нулю — ранг = r. Это экономит перебор.

Полный разбор

Найти ранг A = 321220−110451  (3 строки, 4 столбца ⟹ ранг ≤ 3).

Порядок 1: элемент 3 ≠ 0 ⟹ ранг ≥ 1.
Порядок 2: берём строки 1,2 и столбцы 1,2: 3220 = 3·0 − 2·2 = −4 ≠ 0 ⟹ ранг ≥ 2. Это наш «опорный» (базисный) минор.
Порядок 3: окаймляем его — берём все 3 строки и добавляем к столбцам 1,2 по одному из оставшихся (3 или 4). Плюс проверим и другие тройки столбцов. Всего 4 минора 3×3:
столбцы (1,2,3): 32120−1045 = 3·(0·5 − (−1)·4) − 2·(2·5 − (−1)·0) + 1·(2·4 − 0·0) = 12 − 20 + 8 = 0
столбцы (1,2,4): = −12 − 4 + 16 = 0;   столбцы (1,3,4): = −18 − 2 + 20 = 0;   столбцы (2,3,4): = −12 + 4 + 8 = 0.
Все миноры 3-го порядка равны нулю ⟹ наивысший ненулевой порядок = 2 ⟹ ранг = 2.

Смысл: третья строка выражается через первые две, «новой информации» она не несёт — поэтому независимых строк ровно 2.

Связь ранга с линейной зависимостью

Теорема о базисном миноре

Строки (и столбцы), на которых стоит базисный минор, линейно независимы, а каждая другая строка — их линейная комбинация.

Покажем на числах

Берём A = 321220−110451. Ранг = 2, значит базисный минор — порядка 2. Возьмём его на строках 1, 2 и столбцах 1, 2 (левый верхний угол, выделен):

базисный минор = 3220 = 3·0 − 2·2 = −4 ≠ 0.

Он стоит на строках 1 и 2 — по теореме эти две строки независимы. А строка 3 выражается через них:

строка 3 = 2·(строка 1) − 3·(строка 2):   2·(3,2,1,2) − 3·(2,0,−1,1) = (0, 4, 5, 1) ✓ — это и есть строка 3.

Теорема о ранге

Ранг = максимальному числу линейно независимых строк (= независимых столбцов).

макс. число ЛНЗ строк = макс. число ЛНЗ столбцов = rang A

В нашем примере: независимых строк 2 (строки 1 и 2), значит ранг = 2.

Критерий det A = 0

Теорема

Для квадратной матрицы: det A = 0 ⟺ строки (столбцы) линейно зависимы.

Пример — на числах

Матрица B = 123246012. Посчитаем определитель (Саррюс):

det B = (1·4·2 + 2·6·0 + 3·2·1) − (3·4·0 + 1·6·1 + 2·2·2) = (8 + 0 + 6) − (0 + 6 + 8) = 14 − 14 = 0.

И правда: строка 2 = 2·(строка 1), ведь (2, 4, 6) = 2·(1, 2, 3) — строки зависимы. Как и говорит критерий: det = 0 ⟺ строки зависимы.

Почему так

Если det A ≠ 0, весь определитель — базисный минор порядка n, и все n строк независимы. Если det A = 0, то ранг < n — независимых строк меньше, какая-то выражается через другие (зависимость). Это связывает свойство 5 определителей, ранг и линейную зависимость в одно.

Четыре типа преобразований

Это «разрешённые» действия над матрицей, которыми её упрощают. Покажем каждый на числах.

Тип 1 — перестановка строк/столбцов 1234 → (поменяли строки) → 3412
Тип 2 — умножение строки/столбца на λ ≠ 0 2413 → (1-ю строку ×½) → 1213
Тип 3 — прибавление другой строки, умноженной на λ 1234 → (R₂ − 3·R₁) → 120−2  (это главный рабочий приём — им «зануляют»)
Тип 4 — транспонирование 123456 → 142536
Эквивалентные матрицы

Матрицы A и B эквивалентны (A ~ B), если одна получается из другой конечным числом таких преобразований.

Ключевая теорема

Элементарные преобразования не меняют ранг матрицы. Поэтому ими можно свободно упрощать матрицу и считать ранг у простой — он будет тот же.

Канонический вид

Определение

Каноническая матрица — та, у которой в начале главной диагонали стоят несколько единиц, а всё остальное — нули. Например 100010000 — две единицы.

Утверждение

Любую матрицу элементарными преобразованиями приводят к каноническому (или ступенчатому) виду, и тогда ранг = числу единиц на диагонали = числу ненулевых строк. Это второй способ считать ранг — обычно быстрее перебора миноров.

Система 3×3 по правилу Крамера

Решим систему:

x + y + z = 6
2x − y + z = 3
x + 2y − z = 2
Что за обозначения: Δ — определитель из коэффициентов при x, y, z (матрица системы). Δx — тот же определитель, но первый столбец заменён на столбец правых частей (6, 3, 2); аналогично Δy (заменяем 2-й столбец), Δz (3-й). Тогда x = Δx/Δ, y = Δy/Δ, z = Δz/Δ.

Шаг 1. Главный определитель Δ

Выписываем коэффициенты (по столбцам — при x, при y, при z) и считаем определитель разложением по первой строке:

Δ = 1112−1112−1 = 1·−112−1 − 1·211−1 + 1·2−112
= 1·(1 − 2) − 1·(−2 − 1) + 1·(4 + 1) = −1 + 3 + 5 = 7. Δ ≠ 0 — значит решение единственно.

Шаг 2. Δx (1-й столбец → правые части 6, 3, 2)

Δx = 6113−1122−1 = 6·(1 − 2) − 1·(−3 − 2) + 1·(6 + 2) = −6 + 5 + 8 = 7
⟹ x = ΔxΔ = 77 = 1.

Шаг 3. Δy (2-й столбец → 6, 3, 2)

Δy = 16123112−1 = 1·(−3 − 2) − 6·(−2 − 1) + 1·(4 − 3) = −5 + 18 + 1 = 14 ⟹ y = 147 = 2.

Шаг 4. Δz (3-й столбец → 6, 3, 2)

Δz = 1162−13122 = 1·(−2 − 6) − 1·(4 − 3) + 6·(4 + 1) = −8 − 1 + 30 = 21 ⟹ z = 217 = 3.
Ответ: (x, y, z) = (1, 2, 3). Проверка: 1 + 2 + 3 = 6 ✓,   2 − 2 + 3 = 3 ✓,   1 + 4 − 3 = 2 ✓.

Система 4×4 по правилу Крамера

Решим систему из четырёх уравнений:

2x₁ + x₂ = 4
x₁ + 2x₂ + x₃ = 8
x₂ + 2x₃ + x₄ = 12
x₃ + 2x₄ = 11

Матрица коэффициентов A и правые части B:

A = 2100121001210012,   B = (4, 8, 12, 11).   Та же схема: xi = Δi/Δ, где Δi — Δ с i-м столбцом, заменённым на B.

Шаг 1. Главный определитель Δ

Δ = 2100121001210012. Раскладываем по первой строке (два нуля): Δ = 2·210121012 − 1·110021012
Первый 3×3 = 2·(4−1) − 1·(2−0) + 0 = 6 − 2 = 4; второй 3×3 = 1·(4−1) − 1·(0−0) + 0 = 3. Значит Δ = 2·4 − 1·3 = 5 ≠ 0.

Δ₁ = 410082101212111012 = 4·210121012 − 1·81012211112
= 4·4 − 1·(8·3 − 1·13) = 16 − 1·(24 − 13) = 16 − 11 = 5 ⟹ x₁ = 55 = 1.

Шаг 3. Остальные столбцы

Δ₂ = 10, Δ₃ = 15, Δ₄ = 20 (считаются точно так же — разложением по столбцу с нулями).
Ответ: x = (Δ₁, Δ₂, Δ₃, Δ₄)/Δ = (5, 10, 15, 20)/5 = (1, 2, 3, 4). Проверка в 1-м уравнении: 2·1 + 2 = 4 ✓, в последнем: 3 + 2·4 = 11 ✓.

Для 4×4 всё то же самое — формула xi = Δi/Δ. Пять определителей 4×4 раскрываем разложением по строке/столбцу с нулями — так они сводятся к 3×3 (глава «Определители» → «Методы»).

Задачи для разбора: системы и ранг

Сначала реши сам, потом раскрой ответ.

1. Совместна ли система?   x + y = 1,   2x + 2y = 3.

Ответ
rang A = 1, но rang(A|B) = 2 (строки в (A|B) не пропорциональны). Ранги разные ⟹ по Кронекеру–Капелли система несовместна, решений нет.

2. Реши систему и запиши общее решение:   x + y + z = 3,   x − y + 2z = 0.

Ответ
Ранг = 2, неизвестных 3 ⟹ одна свободная. Главные x, y; свободная z. Переносим z: x + y = 3 − z; x − y = −2z.
Складываем/вычитаем: 2x = 3 − 3z ⟹ x = (3 − 3z)/2; y = 3 − z − x = (3 + z)/2.
Общее решение: (x, y, z) = ((3−3z)/2, (3+z)/2, z), z — любое. При z = 1: (0, 2, 1).

3. Найди ранг 123246111.

Ответ
2-я строка = 2·(1-я) — зависима. Останутся две независимые строки (1-я и 3-я), минор 1211 = 1·1 − 2·1 = −1 ≠ 0. Ранг = 2.

4. Линейно зависимы ли строки (1, 2), (3, 6)?

Ответ
(3, 6) = 3·(1, 2) ⟹ 3·(1,2) − 1·(3,6) = 0, коэффициенты ненулевые ⟹ линейно зависимы. Определитель 1236 = 1·6 − 2·3 = 0 это подтверждает.

Алгоритм решения произвольной СЛАУ

Совместная система

Система называется совместной, если у неё есть хотя бы одно решение. По теореме Кронекера–Капелли это ровно когда rang A = rang (A|B) (ранг матрицы коэффициентов = ранг расширенной матрицы).

Обозначим r = rang A, n — число неизвестных.
  • r = n  ⟹ система определённая: ровно одно решение (∃! решение).
  • r < n  ⟹ система неопределённая: бесконечно много решений (появляются свободные неизвестные).
  • rang A < rang (A|B)  ⟹ система несовместна: решений нет.

Четыре шага

Шаг 1. Вычисляем rang A и rang (A|B). Если система совместна — выбираем базисный минор порядка r (ненулевой минор наибольшего порядка).
Шаг 2. Оставляем r уравнений, из коэффициентов которых составлен базисный минор. Неизвестные, вошедшие в базисный минор, — главные (их r штук), оставляем слева. Остальные n − r — свободные, переносим вправо.
Шаг 3. По Крамеру или Гауссу выражаем главные неизвестные через свободные. Полученные равенства — общее решение СЛАУ.
Шаг 4. Придавая свободным неизвестным любые числовые значения, находим значения главных ⟹ получаем частные решения.
Полный числовой разбор

Решить систему:

x₁ + 2x₂ + x₃ = 4
2x₁ + 4x₂ + 3x₃ = 9
Шаг 1 (ранги). Вычтем из 2-й строки удвоенную 1-ю: (2−2·1, 4−2·2, 3−2·1 | 9−2·4) = (0, 0, 1 | 1). Осталось две ненулевые строки ⟹ rang A = rang (A|B) = 2. Система совместна. Неизвестных n = 3, значит r = 2 < 3 — решений бесконечно много, свободных: n − r = 1.
Шаг 2 (базисный минор). Берём столбцы при x₁ и x₃: минор 1123 = 1·3 − 1·2 = 1 ≠ 0. Значит главные — x₁, x₃, свободная — x₂. Переносим x₂ вправо:
x₁ + x₃ = 4 − 2x₂
2x₁ + 3x₃ = 9 − 4x₂
Шаг 3 (выражаем главные). Умножим первое на 3: 3x₁ + 3x₃ = 12 − 6x₂. Вычтем второе: x₁ = 3 − 2x₂. Тогда x₃ = (4 − 2x₂) − x₁ = 4 − 2x₂ − 3 + 2x₂ = 1.
Общее решение:  (x₁, x₂, x₃) = (3 − 2x₂,  x₂,  1),  где x₂ — любое число.
Шаг 4 (частные). x₂ = 0 ⟹ (3, 0, 1);  x₂ = 1 ⟹ (1, 1, 1). Проверка (1,1,1): 1+2+1 = 4 ✓, 2+4+3 = 9 ✓.

Однородные системы: AX = 0

Однородная СЛАУ

Это система, где все правые части равны нулю:

ai1x₁ + ai2x₂ + … + ainxn = 0,   i = 1, …, m

Она всегда совместна: подставив x₁ = x₂ = … = xn = 0, получаем верные равенства. Это нулевое (тривиальное) решение. Поэтому всегда rang A = rang (A|0).

Главный вопрос

Нулевое решение есть всегда — скучно. Интересно: есть ли ненулевое решение? Ответ зависит только от соотношения ранга и числа неизвестных.

Теорема 1

Однородная система имеет ненулевое решение тогда и только тогда, когда r = rang A < n (ранг меньше числа неизвестных).

Почему: если r = n — решение единственное, а нулевое уже есть, значит других нет. Если r < n — система неопределённая, появляются свободные неизвестные ⟹ бесконечно много решений, среди них есть ненулевые. (Случай r > n невозможен.)
Пример: находим ненулевые решения
2x₁ + x₂ − x₃ = 0
x₁ − x₂ + 2x₃ = 0
n = 3, уравнений 2, rang A = 2 < 3 ⟹ по Теореме 1 есть ненулевые решения. Свободная: x₃ = t. Главные x₁, x₂:
2x₁ + x₂ = t;   x₁ − x₂ = −2t. Сложим: 3x₁ = −t ⟹ x₁ = −t/3. Тогда x₂ = x₁ + 2t = −t/3 + 2t = 5t/3.
Решение: (−t/3,  5t/3,  t). Возьмём t = 3 (чтобы убрать дроби): (−1, 5, 3). Проверка: 2·(−1)+5−3 = 0 ✓, (−1)−5+2·3 = 0 ✓. Любое кратное c·(−1, 5, 3) — тоже решение.
Теорема 2 (для квадратной системы n×n)

Однородная система из n уравнений и n неизвестных имеет ненулевое решение ⟺ её определитель Δ = det A = 0.

Идея доказательства. Если det A ≠ 0, то по Крамеру xi = Δi/Δ, а все Δi = 0 (столбец свободных членов нулевой) ⟹ все xi = 0 — только нулевое. Значит ненулевое возможно лишь при det A = 0 (тогда rang A = r < n).
Два случая рядом

det ≠ 0:  x + y = 0,  x − y = 0.  Δ = 111−1 = −2 ≠ 0 ⟹ только (0, 0).

det = 0:  x + y = 0,  2x + 2y = 0.  Δ = 1122 = 0 ⟹ y = −x, есть ненулевые: t·(1, −1).

Фундаментальная система решений

Свойства решений однородной системы

Пусть e₁ = (α₁, …, αn) и e₂ = (β₁, …, βn) — решения однородной СЛАУ. Тогда:

  • C·e₁ = (Cα₁, …, Cαn) — тоже решение (любое C ∈ ℝ);
  • e₁ + e₂ = (α₁+β₁, …, αn+βn) — тоже решение;
  • значит и любая комбинация c₁e₁ + c₂e₂ — решение.
То есть все решения однородной системы образуют линейное пространство: их можно складывать и умножать на числа, не выходя за пределы множества решений.
Фундаментальная система решений (ФСР)

Это базис пространства решений — такая система решений Y₁, Y₂, …, Yk, что:

  1. решения Y₁, …, Yk линейно независимы;
  2. любое решение Y представимо как Y = c₁Y₁ + … + ckYk.
Теорема о построении ФСР

Любая однородная система имеет ФСР, состоящую из k = n − r решений, где r = rang A. (Столько же, сколько свободных неизвестных.)

Как строят каноническую ФСР. Главные неизвестные выражают через свободные, затем свободным по очереди придают значения строк единичной матрицы: первой свободной — (1, 0, …, 0), второй — (0, 1, …, 0), и т. д. Получается n − r решений; у них «единичный» блок ⟹ они заведомо линейно независимы.
Строим ФСР по шагам

Система из одного уравнения, три неизвестных:

x₁ + x₂ + x₃ = 0
r = 1, n = 3 ⟹ свободных n − r = 2. Главная x₁, свободные x₂, x₃. Выражаем: x₁ = −x₂ − x₃.
Y₁: свободные (x₂, x₃) = (1, 0) ⟹ x₁ = −1.  Y₁ = (−1, 1, 0).
Y₂: свободные (x₂, x₃) = (0, 1) ⟹ x₁ = −1.  Y₂ = (−1, 0, 1).
Проверка: −1+1+0 = 0 ✓, −1+0+1 = 0 ✓. Y₁, Y₂ линейно независимы (разные свободные блоки).
Общее решение: X = c₁Y₁ + c₂Y₂ = (−c₁ − c₂,  c₁,  c₂),  c₁, c₂ — любые.

ФСР определена не единственным образом: свободным можно придавать любые значения (лишь бы соответствующий определитель ≠ 0). Но любые две ФСР одной системы состоят из одинакового числа решений — n − r.

Неоднородные системы: AX = B

Приведённая система

Для неоднородной системы AX = B (B ≠ 0) система AX = 0 называется приведённой (однородной). Их решения тесно связаны.

Теорема 1

Сумма любого решения неоднородной системы и любого решения приведённой однородной — снова решение неоднородной.

AX₁ = B,  AX₂ = 0  ⟹  A(X₁ + X₂) = AX₁ + AX₂ = B + 0 = B. ✓
Теорема 2

Разность двух любых решений неоднородной системы — решение приведённой однородной.

AX₁ = B,  AX₂ = B  ⟹  A(X₁ − X₂) = B − B = 0. ✓
Теорема 3 (структура общего решения)

Общее решение неоднородной системы = любое частное решение неоднородной плюс общее решение приведённой однородной:

X = x* + Xо.о.  =  x* + Σ cjYj

x* — частное решение неоднородной;  Xо.о. — общее решение однородной (ФСР × константы).

Почему: пусть X — любое решение неоднородной, x* — какое-то её частное. По Теореме 2 разность X − x* = Xо.о. — решение приведённой ⟹ X = x* + Xо.о.
Собираем решение из двух частей
x₁ + x₂ + x₃ = 2
Частное x*. Берём свободные x₂ = x₃ = 0 ⟹ x₁ = 2.  x* = (2, 0, 0).
Однородная часть. Приведённая x₁ + x₂ + x₃ = 0 — её ФСР мы уже построили: Y₁ = (−1, 1, 0), Y₂ = (−1, 0, 1).
Общее решение: X = (2, 0, 0) + c₁(−1, 1, 0) + c₂(−1, 0, 1) = (2 − c₁ − c₂,  c₁,  c₂).
Проверка: (2 − c₁ − c₂) + c₁ + c₂ = 2 ✓ при любых c₁, c₂. При c₁ = c₂ = 0 возвращаемся к x* = (2, 0, 0).
Итоговый алгоритм неоднородной СЛАУ: (1) найти любое частное решение x*; (2) найти ФСР приведённой однородной; (3) записать X = x* + c₁Y₁ + … + cn−rYn−r.
