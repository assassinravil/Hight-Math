# Высшая математика — интерактивный конспект

Статический сайт-конспект по линейной алгебре и математическому анализу:
теория с примерами, пошаговые разборы задач и интерактивы.

## Страницы
- `index.html` — главная (портал)
- `linear-algebra.html` — матрицы, определители, обратная, ранг, СЛАУ
- `sets.html` — множества и функции
- `limits.html` — пределы и последовательности
- `complex.html` — комплексные числа
- `.nojekyll` — отключает Jekyll, GitHub отдаёт файлы как есть

## Как выложить на GitHub Pages
1. Создай репозиторий на GitHub.
2. Залей в него все эти файлы (`index.html` должен лежать в корне репозитория).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`

Всё работает офлайн: стили, скрипты и интерактивы встроены прямо в HTML, внешних зависимостей нет. Интерфейс адаптирован под телефон (меню «☰ Разделы» слева).
