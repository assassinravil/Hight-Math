Приращение аргумента и функции

О чём речь

Производная меряет, как быстро меняется функция. Чтобы это измерить, сдвигают аргумент на маленькую величину и смотрят, насколько изменился результат.

Определения
  • x — независимый аргумент;
  • Δx — приращение аргумента (на сколько сдвинули x);
  • Δy = f(x + Δx) − f(x) — приращение функции (на сколько изменилось значение).
Сдвинули аргумент на Δx (горизонтальный катет) — функция выросла на Δy (вертикальный катет). Синяя линия через P и Q — секущая.
На числах: f(x) = x²

Возьмём x = 3, сдвинем на Δx = 0,1 ⟹ x + Δx = 3,1.

Δy = f(3,1) − f(3) = 3,1² − 3² = 9,61 − 9 = 0,61.
Средняя скорость изменения: ΔyΔx = 0,610,1 = 6,1. (Это почти f′(3) = 6 — см. следующий раздел.)

Определение производной

Определение
y′(x) = limΔx→0 ΔyΔx = limΔx→0 f(x + Δx) − f(x)Δx

Производная — это предел отношения приращения функции к приращению аргумента, когда Δx стремится к нулю.

Считаем производную по определению: f(x) = x² в точке x₀ = 2

Составим отношение Δy/Δx и устремим Δx → 0:

Δy = f(2 + Δx) − f(2) = (2 + Δx)² − 4 = 4 + 4Δx + Δx² − 4 = 4Δx + Δx².
ΔyΔx = 4Δx + Δx²Δx = 4 + Δx.
При Δx → 0:  4 + Δx → 4.  Значит f′(2) = 4.

Посмотрим, как отношение «подкрадывается» к 4, когда Δx уменьшается:

Δx10,50,10,01→ 0
Δy/Δx = 4 + Δx54,54,14,014

Это ровно то, что показывает интерактив ниже: секущая (наклон Δy/Δx) при Δx → 0 ложится на касательную (наклон f′ = 4).

Геометрия: секущая → касательная

Отношение Δy/Δx — это наклон секущей через две точки P и Q графика. Когда Δx → 0, точка Q подъезжает к P, и секущая превращается в касательную. Её наклон и есть производная.

Функция:

Как смотреть. Сейчас Δx большое — синяя секущая заметно отличается от золотой штриховой касательной, а золотой/розовый треугольник показывает Δx и Δy. Теперь жми «Δx → 0» (или тяни ползунок Δx влево): точка Q съезжает к P, треугольник схлопывается, и секущая ложится ровно на касательную — значения Δy/Δx и f′(x₀) под графиком сходятся. На параболе x² это особенно видно; на sin x кривая у x₀=1 почти прямая, поэтому начни с большого Δx.

Два смысла производной

Геометрический смысл

f′(x₀) = tg α — тангенс угла наклона касательной к графику в точке x₀. Большая производная ⟹ крутая касательная; f′ = 0 ⟹ касательная горизонтальна (вершина, «полка»).

касательная:   y = f(x₀) + f′(x₀)·(x − x₀)
Касательная (золотая) касается графика в точке x₀. Её наклон = f′(x₀) = tg α: сдвигаясь на 1 вправо, поднимаемся на f′(x₀). Чем больше производная — тем круче касательная.
Уравнение касательной на числах

f(x) = x², x₀ = 1.  f(1) = 1,  f′(x) = 2x ⟹ f′(1) = 2.

y = 1 + 2·(x − 1) = 2x − 1. Наклон 2 — значит касательная поднимается на 2 на каждый шаг вправо.
Механический смысл

Если s(t) — путь, пройденный к моменту t, то s′(t) — мгновенная скорость. А v′(t) — ускорение. Производная вообще — это «скорость изменения» любой величины.

Скорость на числах

s(t) = t² (метры). Средняя скорость за [2; 2,1]: (2,1² − 2²)/0,1 = 4,1 м/с. Мгновенная в t = 2: s′(t) = 2t ⟹ s′(2) = 4 м/с.

Четыре правила

Правила
  1. (c·f)′ = c·f′  — константа выносится;
  2. (f + g)′ = f′ + g′  — сумма почленно;
  3. (f·g)′ = f′·g + f·g′  — произведение;
  4. (fg)′ = f′·g − f·g′g²  — частное.
Произведение

y = x²·sin x.  f = x² (f′ = 2x), g = sin x (g′ = cos x).

y′ = 2x·sin x + x²·cos x.
Частное (из лекции)

y = x³ − 1x³ + 1.  f = x³−1 (f′ = 3x²), g = x³+1 (g′ = 3x²).

y′ = 3x²(x³+1) − 3x²(x³−1)(x³+1)² = 3x²·[(x³+1) − (x³−1)](x³+1)² = 3x²·2(x³+1)² = 6x²(x³+1)².

Производная сложной функции

Цепное правило

Если y = f(u(x)), то

y′(x) = f′(u)·u′(x)  =  dfdu·dudx

«Производим внешнюю функцию, не трогая начинку, затем домножаем на производную начинки.»

Разминка

y = sin(2x): внешняя sin, внутренняя 2x.  y′ = cos(2x)·(2x)′ = 2cos(2x).

y = ex²:  y′ = ex²·(x²)′ = 2x·ex².

Логарифм дроби (из лекции)

y = ln 1x² + 2x + 5 = −ln(x² + 2x + 5).

y′ = −1x²+2x+5·(x²+2x+5)′ = −2x + 2x² + 2x + 5.
Степень тригонометрии (из лекции)

y = 5√(sin(x²+3x+5)) = (sin(x²+3x+5))1/5. Три слоя: степень → sin → многочлен.

y′ = 15(sin u)−4/5·cos u·(2x+3),  где u = x²+3x+5.
= (2x + 3)·cos(x²+3x+5)5·5√(sin⁴(x²+3x+5)).

Сам: y = cos(2x)/(1 + sin 2x). Найди y′.

Решение
Частное: f = cos2x (f′ = −2sin2x), g = 1+sin2x (g′ = 2cos2x).
y′ = −2sin2x·(1+sin2x) − cos2x·2cos2x(1+sin2x)² = −2sin2x − 2sin²2x − 2cos²2x(1+sin2x)².
Используем sin² + cos² = 1: числитель = −2sin2x − 2 = −2(1 + sin2x). Сокращаем: y′ = −21 + sin2x.

Логарифмическое дифференцирование

Когда применять

Если переменная стоит и в основании, и в показателе (как xx), или функция — это длинное произведение/частное корней. Сначала логарифмируем, тогда степени станут множителями, а произведения — суммами.

Схема

Пусть y = y(x). Прологарифмируем: ln y = ln y(x). Продифференцируем обе части (слева по цепному правилу (ln y)′ = y′/y):

y′(x) = y(x)·(ln y(x))′
Классика: (xˣ)′
Обозначим саму функцию за y, то есть y = xˣ (это и есть то, что дифференцируем). Теперь прологарифмируем обе части:
ln y = ln xˣ = x·ln x.  (слева ln y, потому что y = xˣ)
(x·ln x)′ = 1·ln x + x·1x = ln x + 1.
y′ = y·(ln x + 1) = xˣ(ln x + 1).
Корень из дроби (из лекции)

y = √(x(x−1)x−2).

ln y = 12·[ln x + ln(x−1) − ln(x−2)].
(ln y)′ = 12·[1x + 1x−1 − 1x−2].
y′ = 12·√(x(x−1)x−2)·[1x + 1x−1 − 1x−2].

Задачи для разбора

Сначала попробуй сам, потом раскрой решение.

1. y = x2/3·sin 2x (из лекции).

Решение
Произведение: f = x2/3 (f′ = 23x−1/3), g = sin2x (g′ = 2cos2x).
y′ = 23x−1/3·sin2x + x2/3·2cos2x = 2 sin2x3·3√x + 2x2/3cos2x.

2. y = (3x + 1)10.

Решение
Цепное: внешняя (…)10, внутренняя 3x+1 (производная 3).
y′ = 10(3x+1)⁹·3 = 30(3x + 1)⁹.

3. y = ln√(1 + x²1 − x²) (из лекции).

Решение
Упростим логарифм: y = 12[ln(1+x²) − ln(1−x²)].
y′ = 12[2x1+x² − −2x1−x²] = x1+x² + x1−x².
Складываем дроби: = x(1−x²) + x(1+x²)(1+x²)(1−x²) = 2x1 − x⁴.

4. y = e3x·cos x.

Решение
Произведение: (e3x)′ = 3e3x, (cos x)′ = −sin x.
y′ = 3e3xcos x − e3xsin x = e3x(3cos x − sin x).

5. y = (sin x)x (логарифмическое).

Решение
ln y = x·ln(sin x). Дифференцируем: (x ln sin x)′ = ln sin x + x·cos xsin x = ln sin x + x·ctg x.
y′ = (sin x)x·(ln sin x + x·ctg x).

6. Напиши уравнение касательной к y = x³ в точке x₀ = 1.

Решение
f(1) = 1;  f′(x) = 3x² ⟹ f′(1) = 3.
y = 1 + 3(x − 1) = 3x − 2.
