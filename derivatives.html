Приращение аргумента и функции

О чём речь

Производная меряет, как быстро меняется функция. Чтобы это измерить, сдвигают аргумент на маленькую величину и смотрят, насколько изменился результат.

Определения
  • x — независимый аргумент;
  • Δx — приращение аргумента (на сколько сдвинули x);
  • Δy = f(x + Δx) − f(x) — приращение функции (на сколько изменилось значение).
Сдвинули аргумент на Δx (горизонтальный катет) — функция выросла на Δy (вертикальный катет). Синяя линия через P и Q — секущая.
На числах: f(x) = x²

Возьмём x = 3, сдвинем на Δx = 0,1 ⟹ x + Δx = 3,1.

Δy = f(3,1) − f(3) = 3,1² − 3² = 9,61 − 9 = 0,61.
Средняя скорость изменения: ΔyΔx = 0,610,1 = 6,1. (Это почти f′(3) = 6 — см. следующий раздел.)

Определение производной

Определение
y′(x) = limΔx→0 ΔyΔx = limΔx→0 f(x + Δx) − f(x)Δx

Производная — это предел отношения приращения функции к приращению аргумента, когда Δx стремится к нулю.

Считаем производную по определению: f(x) = x² в точке x₀ = 2

Составим отношение Δy/Δx и устремим Δx → 0:

Δy = f(2 + Δx) − f(2) = (2 + Δx)² − 4 = 4 + 4Δx + Δx² − 4 = 4Δx + Δx².
ΔyΔx = 4Δx + Δx²Δx = 4 + Δx.
При Δx → 0:  4 + Δx → 4.  Значит f′(2) = 4.

Посмотрим, как отношение «подкрадывается» к 4, когда Δx уменьшается:

Δx10,50,10,01→ 0
Δy/Δx = 4 + Δx54,54,14,014

Это ровно то, что показывает интерактив ниже: секущая (наклон Δy/Δx) при Δx → 0 ложится на касательную (наклон f′ = 4).

Геометрия: секущая → касательная

Отношение Δy/Δx — это наклон секущей через две точки P и Q графика. Когда Δx → 0, точка Q подъезжает к P, и секущая превращается в касательную. Её наклон и есть производная.

Функция:

Как смотреть. Сейчас Δx большое — синяя секущая заметно отличается от золотой штриховой касательной, а золотой/розовый треугольник показывает Δx и Δy. Теперь жми «Δx → 0» (или тяни ползунок Δx влево): точка Q съезжает к P, треугольник схлопывается, и секущая ложится ровно на касательную — значения Δy/Δx и f′(x₀) под графиком сходятся. На параболе x² это особенно видно; на sin x кривая у x₀=1 почти прямая, поэтому начни с большого Δx.

Два смысла производной

Геометрический смысл

f′(x₀) = tg α — тангенс угла наклона касательной к графику в точке x₀. Большая производная ⟹ крутая касательная; f′ = 0 ⟹ касательная горизонтальна (вершина, «полка»).

касательная:   y = f(x₀) + f′(x₀)·(x − x₀)
Касательная (золотая) касается графика в точке x₀. Её наклон = f′(x₀) = tg α: сдвигаясь на 1 вправо, поднимаемся на f′(x₀). Чем больше производная — тем круче касательная.
Уравнение касательной на числах

f(x) = x², x₀ = 1.  f(1) = 1,  f′(x) = 2x ⟹ f′(1) = 2.

y = 1 + 2·(x − 1) = 2x − 1. Наклон 2 — значит касательная поднимается на 2 на каждый шаг вправо.
Механический смысл

Если s(t) — путь, пройденный к моменту t, то s′(t) — мгновенная скорость. А v′(t) — ускорение. Производная вообще — это «скорость изменения» любой величины.

Скорость на числах

s(t) = t² (метры). Средняя скорость за [2; 2,1]: (2,1² − 2²)/0,1 = 4,1 м/с. Мгновенная в t = 2: s′(t) = 2t ⟹ s′(2) = 4 м/с.

Цепное правило

Если y = f(u(x)), то

Разминка

y = ex²:  y′ = ex²·(x²)′ = 2x·ex².

= (2x + 3)·cos(x²+3x+5)5·5√(sin⁴(x²+3x+5)).

Логарифмическое дифференцирование

Когда применять

Если переменная стоит и в основании, и в показателе (как xx), или функция — это длинное произведение/частное корней. Сначала логарифмируем, тогда степени станут множителями, а произведения — суммами.

Схема

Пусть y = y(x). Прологарифмируем: ln y = ln y(x). Продифференцируем обе части (слева по цепному правилу (ln y)′ = y′/y):

y′(x) = y(x)·(ln y(x))′
Классика: (xˣ)′
Обозначим саму функцию за y, то есть y = xˣ (это и есть то, что дифференцируем). Теперь прологарифмируем обе части:
ln y = ln xˣ = x·ln x.  (слева ln y, потому что y = xˣ)
(x·ln x)′ = 1·ln x + x·1x = ln x + 1.
y′ = y·(ln x + 1) = xˣ(ln x + 1).
Корень из дроби (из лекции)

y = √(x(x−1)x−2).

ln y = 12·[ln x + ln(x−1) − ln(x−2)].
(ln y)′ = 12·[1x + 1x−1 − 1x−2].
y′ = 12·√(x(x−1)x−2)·[1x + 1x−1 − 1x−2].

Односторонние производные

Определение

Можно считать предел Δy/Δx только справа или только слева:

f′₋(x₀) = limΔx→0− ΔyΔx  (слева),    f′₊(x₀) = limΔx→0+ ΔyΔx  (справа)

Производная существует ⟺ обе односторонние конечны и равны: f′₋ = f′₊.

Разбор: y = |x| в точке 0

Справа (x > 0): |x| = x, наклон +1 ⟹ f′₊(0) = +1. Слева (x < 0): |x| = −x, наклон −1 ⟹ f′₋(0) = −1.

+1 ≠ −1 ⟹ производной в нуле нет. На графике это «угол» — резкая смена направления, одной касательной не провести.

В «угле» наклон слева (−1) и справа (+1) разные ⟹ производной нет. Там, где график гладкий (например x²), слева и справа наклон один и тот же — производная есть.

Что значит «функция дифференцируема»

Определение

Функция дифференцируема в x₀, если её приращение раскладывается на линейную часть плюс бесконечно малую высшего порядка:

Δy = A·Δx + o(Δx),   A = const

Коэффициент A — это и есть производная: A = f′(x₀). То есть дифференцируемость ⟺ существует конечная производная.

На числах: f = x², x₀ = 3
Δy = (3 + Δx)² − 3² = 9 + 6Δx + Δx² − 9 = 6·Δx + Δx².
Линейная часть: 6·Δx ⟹ A = 6 = f′(3). Остаток Δx² — это o(Δx), ведь Δx²/Δx = Δx → 0.
Значит f(x)=x² дифференцируема в 3, и f′(3) = 6.
Дифференциал

Линейную часть приращения называют дифференциалом:  dy = f′(x₀)·dx. Это удобное приближение: при малом Δx  Δy ≈ f′(x₀)·Δx.

Приближённое вычисление: √4,1
Берём f(x) = √x, x₀ = 4 (знаем √4 = 2), Δx = 0,1.  f′(x) = 1/(2√x) ⟹ f′(4) = 1/4.
√4,1 ≈ f(4) + f′(4)·0,1 = 2 + 0,25·0,1 = 2,025. (Точное значение 2,0248… — почти совпало.)

Связь с непрерывностью

Теорема

Если f дифференцируема в x₀, то она непрерывна в x₀.

Почему: Δy = f′(x₀)·Δx + o(Δx). При Δx → 0 правая часть → 0, значит Δy → 0 — а это и есть непрерывность (приращение функции стремится к нулю).
Обратное неверно!

Непрерывность не гарантирует дифференцируемость. Пример — та же y = |x|: в нуле она непрерывна (график не разрывается), но производной нет (угол). Гладкость — более сильное требование, чем непрерывность.

Короткая логика: есть производная ⟹ гладко ⟹ непрерывно. Непрерывно ⟹ без разрывов, но могут быть «углы» ⟹ производной может и не быть.

Касательная и нормаль

Две прямые в точке M(x₀, f(x₀))

Касательная — наклон равен производной:

y = f(x₀) + f′(x₀)·(x − x₀)

Нормаль — перпендикуляр к касательной. У перпендикулярных прямых k₁·k₂ = −1, значит наклон нормали = −1/f′(x₀):

y = f(x₀) − 1f′(x₀)·(x − x₀)
На числах: f = x², x₀ = 1
f(1) = 1;  f′(x) = 2x ⟹ f′(1) = 2.
Касательная: y = 1 + 2(x − 1) = 2x − 1.
Нормаль: наклон = −1/2. y = 1 − 12(x − 1) = −x2 + 32.
Проверка перпендикулярности: 2 · (−1/2) = −1 ✓.
Касательная (золотая) и нормаль (розовая) пересекаются в точке касания под прямым углом. Наклоны: 2 и −1/2, произведение −1.

Как составить уравнение касательной — алгоритм

  1. Шаг 1. Вычисли значение функции в точке: f(x₀).
  2. Шаг 2. Найди производную f′(x) и подставь точку: f′(x₀) — это наклon.
  3. Шаг 3. Подставь в формулу y = f(x₀) + f′(x₀)·(x − x₀) и упрости.

Решение

Точка касания: f(2) = 4. Касательная: y = 4 + 4(x − 2) = 4x − 4.
Здесь мы шли «от наклона к точке» — частый тип задач.

7. Где касательная к y = x³ − 3x горизонтальна?

Решение
Горизонтальна ⟺ наклон 0: f′(x) = 3x² − 3 = 0 ⟹ x² = 1 ⟹ x = ±1.
В x = 1: f(1) = −2 ⟹ касательная y = −2. В x = −1: f(−1) = 2 ⟹ y = 2. Это «вершины» графика.

Производная обратной функции

Правило

Если у y = f(x) есть обратная x = φ(y) и f′(x₀) ≠ 0, то

φ′(y₀) = 1f′(x₀)

«Производная обратной — это единица делить на производную прямой.» Геометрически: графики f и φ симметричны относительно прямой y = x, их наклоны взаимно обратны.

Проверка на числах: y = x³
f(x) = x³, f′(x) = 3x². В точке x = 2: f′(2) = 12, и y = 8.
Обратная: x = y1/3. По правилу её производная в y = 8 равна 1/12.
Прямой подсчёт: (y1/3)′ = 13y−2/3 = 13·8−2/3 = 13·14 = 1/12 ✓.
Так выводят табличные формулы

(arcsin x)′: y = arcsin x ⟹ x = sin y, x′(y) = cos y. Тогда y′ = 1/cos y = 1/√(1−sin²y) = 1/√(1−x²).

(ln x)′: y = ln x ⟹ x = ey, x′(y) = ey. Тогда y′ = 1/ey = 1/eln x = 1/x.

Дифференцирование неявной функции

Идея

Иногда y не выражен явно, а связан с x уравнением F(x, y) = 0 (например, окружность x²+y²=25). Тогда дифференцируем всё уравнение по x, помня, что y — это функция от x (поэтому y² даёт 2y·y′ по цепному правилу), и выражаем y′.

Разминка: окружность x² + y² = 25
Дифференцируем по x: 2x + 2y·y′ = 0 ⟹ y′ = −x/y.
В точке (3, 4): y′ = −3/4 (наклон касательной к окружности).
Из лекции: x³ − 2x²y² + 5x + y − 5 = 0, найти y′(1), если y(1) = 1
Дифференцируем почленно по x (у члена 2x²y² — правило произведения, и y²→2y·y′):
3x² − (4x·y² + 2x²·2y·y′) + 5 + y′ = 0  ⟹  3x² − 4xy² − 4x²y·y′ + 5 + y′ = 0.
Собираем y′:  y′·(1 − 4x²y) = 4xy² − 3x² − 5  ⟹  y′ = 4xy² − 3x² − 51 − 4x²y.
Подставляем x = 1, y = 1:  y′(1) = 4 − 3 − 51 − 4 = −4−3 = 43.

Ещё задачи

Правило одно: дифференцируем обе части по x, у каждого y появляется множитель y′, затем собираем y′.

1. xy = 1. Найди y′.

Решение
(xy)′ = 1·y + x·y′ = 0 (производная правой части 1 — ноль).
y + x·y′ = 0 ⟹ y′ = −yx. (Это y = 1/x, и правда y′ = −1/x² = −y/x.)

2. x² + xy + y² = 7. Найди y′, затем y′ в точке (1, 2).

Решение
Дифференцируем: 2x + (y + x·y′) + 2y·y′ = 0  (у члена xy — произведение).
Собираем y′: y′(x + 2y) = −(2x + y) ⟹ y′ = −2x + yx + 2y.
В точке (1, 2): y′ = −2 + 21 + 4 = −45.

3. ey + xy = e. Найди y′ в точке (0, 1).

Решение
Дифференцируем: ey·y′ + (y + x·y′) = 0 ⟹ y′(ey + x) = −y ⟹ y′ = −yey + x.
В точке (0, 1): y′ = −1e¹ + 0 = −1e.

4. Найди касательную к окружности x² + y² = 25 в точке (3, 4).

Решение
Неявно: 2x + 2y·y′ = 0 ⟹ y′ = −x/y. В точке (3,4): y′ = −3/4 — это наклон.
Касательная: y = 4 − 34(x − 3) = −34x + 254. (Связали неявную функцию с касательной — как ты и просил.)

Дифференциал подробно

Определение

Дифференциал — это главная линейная часть приращения функции:  dy = f′(x₀)·dx  (где dx = Δx). Полное приращение Δy = f′(x₀)Δx + o(Δx); дифференциал — это первое слагаемое.

Геометрический смысл

Δy — на сколько поднялась кривая; dy — на сколько поднялась касательная на том же шаге Δx. При малом Δx они почти совпадают, разница — бесконечно малая o(Δx).

dy = f′(x₀)·dx — это приращение ординаты касательной. Кривая (Δy, розовый) и касательная (dy, золотой) расходятся лишь на o(Δx).
Инвариантность формы 1-го дифференциала

Формула dy = f′(x)·dx верна и тогда, когда x — не независимая переменная, а сама функция x = x(t). То есть вид дифференциала не меняется — очень удобно при заменах.

Правила нахождения дифференциала

Те же, что для производной, только с d:  d(cu) = c·du;  d(u+v) = du+dv;  d(uv) = v·du + u·dv;  d(uv) = v·du − u·dvv².

Приближённое вычисление через дифференциал: sin 31°
Дано: нужно оценить sin 31°, не считая синус точно. Формула: f(x₀ + Δx) ≈ f(x₀) + f′(x₀)·Δx.
Шаг 1. Выбираем «удобную» точку рядом: x₀ = 30° = π/6, для неё знаем sin30° = 0,5 и cos30° = √3/2 ≈ 0,866.
Шаг 2. Находим Δx — расстояние до неё: Δx = 1° = π/180 ≈ 0,01745.
Шаг 3. f′ = cos x, значит f′(30°) = 0,866.
Шаг 4. Подставляем: sin 31° ≈ 0,5 + 0,866·0,01745 ≈ 0,515.
Проверка: точное значение 0,5150… — попали.

Производные высших порядков

Определение

Вторая производная — производная от первой: y″ = (y′)′. Дальше по индукции: y⁽ⁿ⁾ = (y⁽ⁿ⁻¹⁾)′.

На числах

y = x⁴:  y′ = 4x³,  y″ = 12x²,  y‴ = 24x,  y⁗ = 24,  y⁽⁵⁾ = 0.

y = sin x:  y′ = cos x,  y″ = −sin x,  y‴ = −cos x,  y⁗ = sin x (период 4 — возвращается к себе).

Правила n-кратного дифференцирования

(c·u)⁽ⁿ⁾ = c·u⁽ⁿ⁾;  (u+v)⁽ⁿ⁾ = u⁽ⁿ⁾ + v⁽ⁿ⁾;  для произведения — формула Лейбница:

(u·v)⁽ⁿ⁾ = Σk=0n Cnk·u⁽ⁿ⁻ᵏ⁾·v⁽ᵏ⁾,   Cnk = n!k!(n−k)!

Она как бином Ньютона, только степени заменены на производные.

Формула Лейбница: (x²·eˣ)″
n = 2: (uv)″ = u″v + 2u′v′ + uv″. Берём u = x² (u′=2x, u″=2), v = eˣ (v′=v″=eˣ).
= 2·eˣ + 2·2x·eˣ + x²·eˣ = eˣ(x² + 4x + 2).
n-я производная типовых функций

y = aˣ: y⁽ⁿ⁾ = aˣ·lnⁿa.  (Например (2ˣ)″ = 2ˣ·ln²2.)

y = eˣ: y⁽ⁿ⁾ = eˣ (все производные одинаковы).

y = sin(ax): y⁽ⁿ⁾ = aⁿ·sin(ax + n·π2) — каждая производная «сдвигает фазу» на π/2.

Проверка формулы для sin

y = sin x (a=1): y′ = sin(x + π/2) = cos x ✓; y″ = sin(x + π) = −sin x ✓; y‴ = sin(x + 3π/2) = −cos x ✓. Формула работает.

Сложные разборы

Здесь нужно угадать закономерность для n-й производной. Сначала попробуй сам.

1. Найди n-ю производную y = 11 − x.

Решение
Перепишем y = (1 − x)−1.  y′ = −1·(1−x)−2·(−1) = (1−x)−2.
y″ = −2·(1−x)−3·(−1) = 2·(1−x)−3;  y‴ = 2·3·(1−x)−4 = 6·(1−x)−4.
Видна закономерность: множители 1, 2, 6 = n! и степень растёт.  y⁽ⁿ⁾ = n!(1 − x)n+1.

2. Найди n-ю производную y = ln(1 + x).

Решение
y′ = (1+x)−1.  y″ = −(1+x)−2;  y‴ = 2(1+x)−3;  y⁗ = −6(1+x)−4.
Знаки чередуются, множители — (n−1)!.  y⁽ⁿ⁾ = (−1)n−1·(n − 1)!(1 + x)n.

3. (Формула Лейбница, n = 3) Найди (x²·sin x)‴.

Решение
(uv)‴ = u‴v + 3u″v′ + 3u′v″ + uv‴  (коэффициенты 1,3,3,1 = C₃ᵏ). u = x²: u′=2x, u″=2, u‴=0. v = sin x: v′=cos x, v″=−sin x, v‴=−cos x.
= 0·sin x + 3·2·cos x + 3·2x·(−sin x) + x²·(−cos x) = 6cos x − 6x·sin x − x²·cos x.
= (6 − x²)·cos x − 6x·sin x.

4. Найди y″ для y = x·ex и для y = e−3x.

Решение
y = x·eˣ: y′ = eˣ + x·eˣ = (1+x)eˣ; y″ = eˣ + (1+x)eˣ = (2 + x)eˣ.
y = e−3x: y′ = −3e−3x; y″ = 9e−3x. (Вообще y⁽ⁿ⁾ = (−3)ⁿe−3x.)

Точки экстремума

Определения

Точка x₀ — точка максимума, если в её окрестности f(x₀ + Δx) ≤ f(x₀) (значение в x₀ — самое большое рядом). Точка минимума — если f(x₀ + Δx) ≥ f(x₀). И те, и другие называют точками экстремума.

На пальцах

Максимум — «вершина холмика», минимум — «дно ямки». В гладкой точке экстремума касательная горизонтальна, то есть f′(x₀) = 0 (необходимое условие — подробно в следующей теме).

На числах

y = x²: в x₀ = 0 минимум (f(0)=0, вокруг больше). f′(x)=2x, f′(0)=0 ✓.

y = 4 − x²: в x₀ = 0 максимум (f(0)=4, вокруг меньше). f′(0)=0 ✓.

y = x³: f′(0)=0, но экстремума нет — слева функция меньше, справа больше (точка перегиба). Значит f′=0 — лишь необходимое, но не достаточное условие.

Теорема Ферма

Формулировка

Пусть y = f(x) определена и непрерывна в точке x₀, и x₀ — точка экстремума (максимума или минимума). Если в x₀ существует производная, то

f′(x₀) = 0
Почему (на максимуме). Пусть x₀ — максимум, то есть Δy = f(x₀+Δx) − f(x₀) ≤ 0. Смотрим отношение Δy/Δx: при Δx > 0 оно ≤ 0, при Δx < 0 оно ≥ 0. Если производная существует, левый и правый пределы Δy/Δx равны одному числу, которое одновременно ≤ 0 и ≥ 0 ⟹ оно = 0. Значит f′(x₀) = 0.
Геометрический смысл

В точке экстремума касательная горизонтальна (параллельна оси Ox): наклон f′(x₀) = 0.

На вершине касательная ложится горизонтально — её наклон f′(x₀) равен нулю.
Пример на числах
Дано: f(x) = −x² + 4x. Найти точку экстремума и проверить f′ = 0.
Шаг 1. f′(x) = −2x + 4.
Шаг 2. Приравниваем к нулю: −2x + 4 = 0 ⟹ x₀ = 2.
Шаг 3. f(2) = −4 + 8 = 4 — это максимум (ветви параболы вниз).
Ответ: в x₀ = 2 максимум, и f′(2) = −2·2 + 4 = 0 ✓ — теорема Ферма выполнена.
Важно

Ферма требует существования производной. У y = |x| в нуле минимум, но производной нет (угол) — теорема просто не применяется.

Теорема Ролля

Формулировка

Пусть f(x) удовлетворяет трём условиям: (1) непрерывна на [a, b]; (2) дифференцируема на (a, b); (3) f(a) = f(b). Тогда найдётся точка c ∈ (a, b), такая что

f′(c) = 0
Почему. По теореме Вейерштрасса непрерывная на [a,b] функция достигает max и min. Если оба на концах — из f(a)=f(b) следует, что функция постоянна и f′≡0. Иначе экстремум попадает внутрь (a,b), и там по теореме Ферма f′(c)=0.
Геометрия

Если концы на одной высоте, то где-то между ними касательная горизонтальна.

Концы на одной высоте ⟹ между ними есть «вершина» с горизонтальной касательной.
Пример
Дано: f(x) = x² − 4 на [−2, 2]. Проверить Ролля и найти c.
Шаг 1. Условия: многочлен — непрерывен и дифференцируем везде ✓. Концы: f(−2) = 0, f(2) = 0 ⟹ f(−2) = f(b) ✓.
Шаг 2. f′(x) = 2x. Решаем f′(c) = 0: 2c = 0 ⟹ c = 0.
Ответ: c = 0 ∈ (−2, 2) ✓ — в нуле касательная горизонтальна.
Контрпример — когда условие нарушено
f(x) = ∛(x²) = x2/3 на [−1, 1]: концы равны f(−1) = f(1) = 1, функция непрерывна, но в x = 0 не дифференцируема (касп, f′ = (2/3)x−1/3 → ∞).
Условие (2) нарушено ⟹ Ролля не применить, и действительно f′ нигде не равна нулю (f′ = (2/3)/∛x ≠ 0). Все три условия обязательны!

Теорема Лагранжа (о среднем значении)

Формулировка

Если f(x) непрерывна на [a, b] и дифференцируема на (a, b), то найдётся c ∈ (a, b):

f′(c) = f(b) − f(a)b − a

(формула конечных приращений).

Геометрия

Справа — наклон секущей через концы (a, f(a)) и (b, f(b)). Теорема говорит: найдётся точка c, где касательная параллельна этой секущей.

Есть точка c, где касательная (золотая) параллельна секущей через концы (синяя).
Смысл формулы

Перепишем так: f(b) − f(a) = f′(c)·(b − a). То есть всё приращение функции на отрезке равно производной в некоторой средней точке c, умноженной на длину отрезка. Физически: если проехать путь за время [a, b], то средняя скорость на отрезке в какой-то момент c равна мгновенной.

Как доказывают (через Ролля). Вводят вспомогательную функцию F(x) = f(x) − k·x, где k = (f(b)−f(a))/(b−a). Считаем концы: F(a) = f(a) − k·a и F(b) = f(b) − k·b. Подставив k, получаем F(a) = F(b) (ровно так k и подобран). Значит к F применима теорема Ролля ⟹ ∃c ∈ (a,b): F′(c) = 0. Но F′(x) = f′(x) − k, поэтому f′(c) − k = 0 ⟹ f′(c) = k. Это и есть формула.

Примеры (находим точку c)

Пример 1: f(x) = x² на [1, 3]
Дано: f = x², отрезок [1, 3]. Найти c из формулы Лагранжа.
Шаг 1. Правая часть (наклон секущей): f(3) − f(1)3 − 1 = 9 − 12 = 4.
Шаг 2. Производная: f′(x) = 2x.
Шаг 3. Уравнение f′(c) = 4:  2c = 4 ⟹ c = 2.
Ответ: c = 2, и это внутри (1, 3) ✓.
Проверка: f′(2) = 2·2 = 4 — равно наклону секущей ✓. Касательная в x=2 параллельна прямой через (1,1) и (3,9).
Пример 2: f(x) = √x на [1, 4]
Шаг 1. Правая часть: √4 − √14 − 1 = 2 − 13 = 13.
Шаг 2. Производная: f′(x) = (x1/2)′ = 12√x.
Шаг 3. Уравнение 12√c = 13:  2√c = 3 ⟹ √c = 1,5 ⟹ c = 2,25.
Ответ: c = 2,25 ∈ (1, 4) ✓.
Проверка: f′(2,25) = 1/(2·1,5) = 1/3 — совпало с секущей ✓.
Пример 3: f(x) = x³ на [0, 3]
Шаг 1. Правая часть: 27 − 03 − 0 = 9.
Шаг 2. Производная: f′(x) = 3x².
Шаг 3. Уравнение 3c² = 9 ⟹ c² = 3 ⟹ c = √3 ≈ 1,73 (берём положительный корень — он в отрезке).
Ответ: c = √3 ∈ (0, 3) ✓.
Зачем это нужно: доказываем неравенство |sin b − sin a| ≤ |b − a|
Идея: применим формулу Лагранжа к f(x) = sin x на отрезке с концами a и b.
Шаг 1. По теореме: sin b − sin a = f′(c)·(b − a) = cos c·(b − a) для некоторого c между a и b.
Шаг 2. Берём модуль: |sin b − sin a| = |cos c|·|b − a|.
Шаг 3. Всегда |cos c| ≤ 1, поэтому |sin b − sin a| ≤ |b − a|.
Вывод: синус «не растягивает» расстояния — это строго доказано теоремой Лагранжа. Так её применяют для оценок и неравенств.

Теорема Коши (обобщённая о среднем)

Формулировка

Если f(x) и φ(x) непрерывны на [a, b], дифференцируемы на (a, b) и φ′(x) ≠ 0, то найдётся c ∈ (a, b):

f′(c)φ′(c) = f(b) − f(a)φ(b) − φ(a)
О чём это

Лагранж сравнивает приращение одной функции с длиной отрезка. Коши сравнивает приращения двух функций между собой. Условие φ′ ≠ 0 нужно, чтобы знаменатель φ(b) − φ(a) не обратился в ноль (иначе дробь не имеет смысла).

Связь с Лагранжем: если взять φ(x) = x, то φ′ = 1 и φ(b) − φ(a) = b − a — формула Коши превращается в формулу Лагранжа. То есть Лагранж — это Коши с φ(x) = x.
Как доказывают. Вводят F(x) = f(x) − f(b) − f(a)φ(b) − φ(a)·(φ(x) − φ(a)). Проверяют F(a) = F(b) = 0, применяют Ролля ⟹ ∃c: F′(c) = 0 ⟹ f′(c) = f(b)−f(a)φ(b)−φ(a)·φ′(c), откуда и получается формула.

Примеры

Пример 1: f(x) = x², φ(x) = x³ на [1, 2]
Шаг 1. Правая часть: f(2) − f(1)φ(2) − φ(1) = 4 − 18 − 1 = 37.
Шаг 2. Левая часть: f′ = 2x, φ′ = 3x², поэтому f′(c)φ′(c) = 2c3c² = 23c.
Шаг 3. Уравнение: 23c = 37 ⟹ 2·7 = 3·3·c ⟹ 14 = 9c ⟹ c = 149 ≈ 1,556.
Ответ: c = 14/9 ∈ (1, 2) ✓.
Проверка: f′(c)/φ′(c) = 2/(3·14/9) = 2·9/(42) = 18/42 = 3/7 — совпало с правой частью ✓.
Пример 2: f(x) = sin x, φ(x) = cos x на [0, π/2]
Шаг 1. Правая часть: sin(π/2) − sin 0cos(π/2) − cos 0 = 1 − 00 − 1 = −1.
Шаг 2. Левая часть: f′ = cos x, φ′ = −sin x, поэтому f′(c)φ′(c) = cos c−sin c = −ctg c.
Шаг 3. Уравнение: −ctg c = −1 ⟹ ctg c = 1 ⟹ c = π/4.
Ответ: c = π/4 ∈ (0, π/2) ✓.

Правило Лопиталя

Откуда берётся Лопиталь — цепочка теорем

Это не отдельная формула с неба, а вершина целой лестницы. Каждая теорема опирается на предыдущую:

  1. Ферма: в точке экстремума f′ = 0.
  2. Ролль (доказан через Ферма + Вейерштрасса): если f(a) = f(b), то внутри есть c с f′(c) = 0.
  3. Лагранж (доказан через Ролля): f′(c) = (f(b)−f(a))/(b−a).
  4. Коши (обобщение Лагранжа на две функции): f′(c)/φ′(c) = (f(b)−f(a))/(φ(b)−φ(a)).
  5. Лопиталь (доказан через Коши): lim f/g = lim f′/g′ для 0/0 и ∞/∞.

То есть Ферма → Ролль → Лагранж → Коши → Лопиталь. Ниже видно, как именно последний шаг получается из Коши.

Формулировка

Если f(x)/g(x) даёт неопределённость 00 или ∞∞ при x → a, функции дифференцируемы около a, g′ ≠ 0, и существует предел отношения производных, то

limx→a f(x)g(x) = limx→a f′(x)g′(x)
Доказательство для 0/0 (через Коши) — по шагам.
Шаг 1. Раз это 0/0, доопределим (или уже так): f(a) = 0 и g(a) = 0.
Шаг 2. Берём отрезок [a, x] и применяем к f, g теорему Коши: f(x) − f(a)g(x) − g(a) = f′(c)g′(c), где c между a и x.
Шаг 3. Но f(a) = g(a) = 0, поэтому левая часть просто f(x)g(x). Значит f(x)g(x) = f′(c)g′(c).
Шаг 4. При x → a точка c «зажата» между a и x, поэтому c → a тоже. Переходя к пределу: lim f(x)g(x) = lim f′(c)g′(c) = lim f′(x)g′(x). ∎
Для ∞/∞ доказательство аналогичное (чуть техничнее), формула та же.
Порядок действий

Сначала убедись, что это именно 0/0 или ∞/∞ (подставь x = a). Только тогда дифференцируй числитель и знаменатель по отдельности (это не производная частного!). Если снова 0/0 — применяй правило ещё раз.

0/0 — простой: limx→0 (eˣ − 1)/x
Шаг 1. Подстановка: (e⁰ − 1)/0 = 0/0 — можно Лопиталь.
Шаг 2. (eˣ − 1)′ = eˣ; (x)′ = 1 ⟹ предел = lim eˣ/1.
Шаг 3. Подставляем x = 0: e⁰/1 = 1. Ответ: 1.
Проверка: eˣ − 1 ~ x при x→0, отношение x/x = 1 — совпало.
0/0 — дважды: limx→0 (1 − cos x)/x²
Шаг 1. (1 − 1)/0 = 0/0.
Шаг 2. Числитель (1 − cos x)′ = sin x; знаменатель (x²)′ = 2x ⟹ lim sin x/(2x).
Шаг 3. При x = 0: 0/0 — снова. Ещё раз: (sin x)′ = cos x, (2x)′ = 2 ⟹ lim cos x/2.
Шаг 4. При x = 0: cos 0/2 = 1/2. Ответ: 1/2.
Проверка: 1 − cos x ~ x²/2, делим на x² → 1/2 — совпало.
∞/∞: limx→+∞ ln x / x
Шаг 1. При x → ∞: ∞/∞ — можно Лопиталь.
Шаг 2. (ln x)′ = 1/x; (x)′ = 1 ⟹ lim (1/x)/1 = lim 1/x.
Шаг 3. При x → ∞: 1/x → 0. Ответ: 0.
Проверка: логарифм растёт медленнее любой степени x — отношение к x стремится к 0, логично.
∞/∞ (из лекции): limx→+∞ (π/2 − arctg x) / ln(1 + 1/x²)
Шаг 1. π/2 − arctg x → 0 и ln(1 + 1/x²) → 0 — это 0/0 (а не ∞/∞), но правило то же.
Шаг 2. Числитель: (π/2 − arctg x)′ = −1/(1 + x²).
Знаменатель: (ln(1 + 1/x²))′ = 11 + 1/x²·(−2/x³) = −2x³ + x.
Шаг 3. Отношение: −1/(1+x²)−2/(x³+x) = x³ + x2(1 + x²) = x(x²+1)2(x²+1) = x2.
Шаг 4. При x → +∞: x/2 → +∞. Ответ: +∞.
Проверка: числитель π/2 − arctg x ~ 1/x (хвост арктангенса), знаменатель ln(1+1/x²) ~ 1/x²; отношение (1/x)/(1/x²) = x → ∞ — тот же результат.

Раскрытие «хитрых» неопределённостей

Главная мысль

Лопиталь умеет только 0/0 и ∞/∞. Все остальные виды сначала превращают в один из этих двух — и только потом применяют правило. Приёмы превращения:

  • 0·∞ → записать произведение дробью: u·v = u1/v, получится 0/0 или ∞/∞.
  • ∞ − ∞ → привести к общему знаменателю, получится 0/0.
  • 1∞, 0⁰, ∞⁰ (степень с переменным показателем) → прологарифмировать. Схема в 3 шага ниже.
Схема для степенных 1∞, 0⁰, ∞⁰
  1. Обозначить предел за L и взять логарифм: ln L = lim (показатель · ln основания).
  2. Это станет 0·∞ → свести к дроби → посчитать Лопиталем. Получим число A.
  3. Вернуть ответ: ln L = A ⟹ L = eA.

Разбор 1 (вид 0·∞)

limx→+∞ x²·e−2x
Шаг 1. Определяем вид. x² → +∞, а e−2x → 0, значит произведение — это 0·∞.
Шаг 2. Превращаем в дробь. e−2x = 1/e2x, поэтому  x²·e−2x = x²e2x. Теперь вид ∞/∞ — можно Лопиталь.
Шаг 3. Лопиталь (1-й раз). Числитель: (x²)′ = 2x. Знаменатель: (e2x)′ = 2e2x.
Предел стал  lim 2x2e2x = lim xe2x. Подставляем ∞: снова ∞/∞.
Шаг 4. Лопиталь (2-й раз). Числитель: (x)′ = 1. Знаменатель: (e2x)′ = 2e2x.
Предел стал  lim 12e2x.
Шаг 5. Подставляем x → +∞: знаменатель → +∞, дробь → 0.
Ответ: 0.
Проверка: экспонента e2x растёт быстрее любой степени, поэтому x²/e2x → 0 — логично.

Разбор 2 (вид ∞ − ∞)

limx→1 ( 1ln x − 1x − 1 )
Шаг 1. Вид. При x → 1: ln x → 0, значит 1/ln x → ∞; и 1/(x−1) → ∞. Разность — это ∞ − ∞.
Шаг 2. Общий знаменатель. Приводим две дроби к одной:
= limx→1 (x − 1) − ln xln x·(x − 1)
Шаг 3. Проверяем вид. При x = 1: числитель (1−1) − ln 1 = 0; знаменатель ln 1·0 = 0. Это 0/0.
Шаг 4. Лопиталь (1-й раз).
Числитель: (x − 1 − ln x)′ = 1 − 1x.
Знаменатель (произведение): (ln x·(x−1))′ = 1x·(x−1) + ln x·1 = x−1x + ln x.
При x = 1: числитель 1 − 1 = 0, знаменатель 0 + 0 = 0 — снова 0/0.
Шаг 5. Лопиталь (2-й раз).
Числитель: (1 − 1/x)′ = 1x².
Знаменатель: ( (x−1)/x + ln x )′ = (1 − 1/x)′ + (ln x)′ = 1x² + 1x.
Шаг 6. Подставляем x = 1:  1/x²1/x² + 1/x = 11 + 1 = 12.
Ответ: 1/2.
Проверка: около 1 ln x ≈ (x−1) − (x−1)²/2, тогда числитель x−1−ln x ≈ (x−1)²/2, знаменатель ≈ (x−1)²; отношение → 1/2 — совпало.

Разбор 3 (вид 1∞)

limx→0 (cos x)1/x²
Шаг 1. Вид. cos 0 = 1, показатель 1/x² → +∞, значит 1∞ — логарифмируем.
Шаг 2. Берём логарифм. Пусть L — искомый предел. Тогда ln L = limx→0 1x²·ln(cos x) = limx→0 ln(cos x)x².
Шаг 3. Вид дроби. При x = 0: ln(cos 0) = ln 1 = 0, знаменатель 0 ⟹ 0/0.
Шаг 4. Лопиталь. Числитель: (ln cos x)′ = 1cos x·(−sin x) = −tg x. Знаменатель: (x²)′ = 2x.
ln L = limx→0 −tg x2x. Так как tg x ~ x у нуля, это = −x2x → −12.
Шаг 5. Возвращаем ответ. ln L = −1/2 ⟹ L = e−1/2.
Ответ: e−1/2 = 1/√e ≈ 0,607.
Проверка: ln cos x ≈ −x²/2, делим на x² → −1/2 — тот же ln L.

Разбор 4 (виды 0⁰ и ∞⁰)

0⁰: limx→0+ xˣ
Шаг 1. Основание x → 0, показатель x → 0 ⟹ 0⁰. Логарифмируем: ln L = limx→0+ x·ln x (вид 0·∞).
Шаг 2. В дробь: x·ln x = ln x1/x — вид ∞/∞.
Шаг 3. Лопиталь: (ln x)′ = 1/x, (1/x)′ = −1/x². Отношение = 1/x−1/x² = −x → 0.
Шаг 4. ln L = 0 ⟹ L = e⁰ = 1.
∞⁰: limx→+∞ x1/x
Шаг 1. Основание x → ∞, показатель 1/x → 0 ⟹ ∞⁰. ln L = lim ln xx (вид ∞/∞).
Шаг 2. Лопиталь: (ln x)′ = 1/x, (x)′ = 1 ⟹ lim 1/x1 = lim 1/x → 0.
Шаг 3. ln L = 0 ⟹ L = e⁰ = 1.
Шпаргалка. 0·∞ → дробь;  ∞−∞ → общий знаменатель;  степенные 1∞/0⁰/∞⁰ → логарифм: посчитать lim(показатель·ln основания) = A, ответ L = eA.

Средние

1. limx→0 sin 3xsin 5x

Решение по шагам
Шаг 1. При x = 0: sin0/sin0 = 0/0 ⟹ Лопиталь.
Шаг 2. Числитель: (sin 3x)′ = 3cos 3x. Знаменатель: (sin 5x)′ = 5cos 5x.
Шаг 3. lim 3cos 3x5cos 5x, подставляем x=0: 3·15·1 = 3/5.

2. limx→0 1 − cos 2xx²

Решение по шагам
Шаг 1. (1−1)/0 = 0/0.
Шаг 2. Числитель: (1 − cos 2x)′ = 2sin 2x. Знаменатель: (x²)′ = 2x.
Шаг 3. lim 2sin 2x2x = lim sin 2xx — снова 0/0.
Шаг 4. Ещё раз: (sin 2x)′ = 2cos 2x, (x)′ = 1 ⟹ lim 2cos 2x = 2cos0 = 2.
Проверка: 1 − cos2x ~ (2x)²/2 = 2x², делим на x² → 2 ✓.

3. limx→+∞ x³eˣ

Решение по шагам
Шаг 1. ∞/∞ ⟹ Лопиталь (дифференцируем, пока степень не исчезнет).
1-й раз: (x³)′ = 3x², (eˣ)′ = eˣ ⟹ lim 3x²/eˣ — ∞/∞.
2-й раз: 6x/eˣ — ∞/∞.
3-й раз: 6/eˣ → 0. Ответ: 0.
Вывод: eˣ бьёт любую степень xⁿ (приём: Лопиталь n раз обнуляет числитель).

4. limx→0 x − sin xx³

Решение по шагам
Шаг 1. (0−0)/0 = 0/0.
1-й раз: (x − sin x)′ = 1 − cos x, (x³)′ = 3x² ⟹ lim 1 − cos x3x² — 0/0.
2-й раз: (1 − cos x)′ = sin x, (3x²)′ = 6x ⟹ lim sin x6x — 0/0.
3-й раз: (sin x)′ = cos x, (6x)′ = 6 ⟹ lim cos x6 = 16. Ответ: 1/6.

Сложные

5. limx→0 tg x − xx − sin x

Решение по шагам
Шаг 1. (0−0)/(0−0) = 0/0.
Шаг 2. Лопиталь. Числитель: (tg x − x)′ = 1cos²x − 1 = tg²x. Знаменатель: (x − sin x)′ = 1 − cos x.
lim tg²x1 − cos x — опять 0/0.

lim x²x²/2 = 2.

Решение по шагам
Шаг 1. (1 − 1 − 0)/0 = 0/0.
1-й раз: (eˣ − 1 − x)′ = eˣ − 1, (x²)′ = 2x ⟹ lim eˣ − 12x — 0/0.
2-й раз: (eˣ − 1)′ = eˣ, (2x)′ = 2 ⟹ lim eˣ2 = 12. Ответ: 1/2.

7. limx→0+ xsin x  (степень 0⁰)

Решение по шагам
Шаг 1. Основание x → 0, показатель sin x → 0 ⟹ 0⁰. Логарифмируем: ln L = limx→0+ sin x·ln x.
Шаг 2. В дробь: sin x·ln x = ln x1/sin x — вид ∞/∞.
Шаг 3. Проще через эквивалентность: sin x ~ x, поэтому sin x·ln x ~ x·ln x, а limx→0+ x·ln x = 0 (стандартный предел).
Шаг 4. ln L = 0 ⟹ L = e⁰ = 1.

8. limx→0 ( 1x − 1eˣ − 1 )  (вид ∞ − ∞)

Решение по шагам
Шаг 1. Общий знаменатель: = lim (eˣ − 1) − xx(eˣ − 1).
Шаг 2. Вид. При x=0: числитель (1−1)−0 = 0, знаменатель 0·0 = 0 ⟹ 0/0.
1-й Лопиталь. Числитель: (eˣ − 1 − x)′ = eˣ − 1. Знаменатель: (x(eˣ−1))′ = (eˣ−1) + x·eˣ.
При x=0: 0/(0+0) = 0/0 — снова.
2-й Лопиталь. Числитель: (eˣ − 1)′ = eˣ. Знаменатель: ((eˣ−1) + x·eˣ)′ = eˣ + (eˣ + x·eˣ) = 2eˣ + x·eˣ.
Подставляем x=0: e⁰2e⁰ + 0 = 12. Ответ: 1/2.
