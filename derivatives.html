Приращение аргумента и функции

О чём речь

Производная меряет, как быстро меняется функция. Чтобы это измерить, сдвигают аргумент на маленькую величину и смотрят, насколько изменился результат.

Определения
  • x — независимый аргумент;
  • Δx — приращение аргумента (на сколько сдвинули x);
  • Δy = f(x + Δx) − f(x) — приращение функции (на сколько изменилось значение).
Сдвинули аргумент на Δx (горизонтальный катет) — функция выросла на Δy (вертикальный катет). Синяя линия через P и Q — секущая.
На числах: f(x) = x²

Возьмём x = 3, сдвинем на Δx = 0,1 ⟹ x + Δx = 3,1.

Δy = f(3,1) − f(3) = 3,1² − 3² = 9,61 − 9 = 0,61.
Средняя скорость изменения: ΔyΔx = 0,610,1 = 6,1. (Это почти f′(3) = 6 — см. следующий раздел.)

Определение производной

Определение
y′(x) = limΔx→0 ΔyΔx = limΔx→0 f(x + Δx) − f(x)Δx

Производная — это предел отношения приращения функции к приращению аргумента, когда Δx стремится к нулю.

Считаем производную по определению: f(x) = x² в точке x₀ = 2

Составим отношение Δy/Δx и устремим Δx → 0:

Δy = f(2 + Δx) − f(2) = (2 + Δx)² − 4 = 4 + 4Δx + Δx² − 4 = 4Δx + Δx².
ΔyΔx = 4Δx + Δx²Δx = 4 + Δx.
При Δx → 0:  4 + Δx → 4.  Значит f′(2) = 4.

Посмотрим, как отношение «подкрадывается» к 4, когда Δx уменьшается:

Δx10,50,10,01→ 0
Δy/Δx = 4 + Δx54,54,14,014

Это ровно то, что показывает интерактив ниже: секущая (наклон Δy/Δx) при Δx → 0 ложится на касательную (наклон f′ = 4).

Геометрия: секущая → касательная

Отношение Δy/Δx — это наклон секущей через две точки P и Q графика. Когда Δx → 0, точка Q подъезжает к P, и секущая превращается в касательную. Её наклон и есть производная.

Функция:

Как смотреть. Сейчас Δx большое — синяя секущая заметно отличается от золотой штриховой касательной, а золотой/розовый треугольник показывает Δx и Δy. Теперь жми «Δx → 0» (или тяни ползунок Δx влево): точка Q съезжает к P, треугольник схлопывается, и секущая ложится ровно на касательную — значения Δy/Δx и f′(x₀) под графиком сходятся. На параболе x² это особенно видно; на sin x кривая у x₀=1 почти прямая, поэтому начни с большого Δx.

Два смысла производной

Геометрический смысл

f′(x₀) = tg α — тангенс угла наклона касательной к графику в точке x₀. Большая производная ⟹ крутая касательная; f′ = 0 ⟹ касательная горизонтальна (вершина, «полка»).

касательная:   y = f(x₀) + f′(x₀)·(x − x₀)
Касательная (золотая) касается графика в точке x₀. Её наклон = f′(x₀) = tg α: сдвигаясь на 1 вправо, поднимаемся на f′(x₀). Чем больше производная — тем круче касательная.
Уравнение касательной на числах

f(x) = x², x₀ = 1.  f(1) = 1,  f′(x) = 2x ⟹ f′(1) = 2.

y = 1 + 2·(x − 1) = 2x − 1. Наклон 2 — значит касательная поднимается на 2 на каждый шаг вправо.
Механический смысл

Если s(t) — путь, пройденный к моменту t, то s′(t) — мгновенная скорость. А v′(t) — ускорение. Производная вообще — это «скорость изменения» любой величины.

Скорость на числах

s(t) = t² (метры). Средняя скорость за [2; 2,1]: (2,1² − 2²)/0,1 = 4,1 м/с. Мгновенная в t = 2: s′(t) = 2t ⟹ s′(2) = 4 м/с.

Производная сложной функции

Цепное правило

Если y = f(u(x)), то

y′(x) = f′(u)·u′(x)  =  dfdu·dudx

«Производим внешнюю функцию, не трогая начинку, затем домножаем на производную начинки.»

Разминка

y = sin(2x): внешняя sin, внутренняя 2x.  y′ = cos(2x)·(2x)′ = 2cos(2x).

y = ex²:  y′ = ex²·(x²)′ = 2x·ex².

Логарифм дроби (из лекции)

y = ln 1x² + 2x + 5 = −ln(x² + 2x + 5).

y′ = −1x²+2x+5·(x²+2x+5)′ = −2x + 2x² + 2x + 5.
Степень тригонометрии (из лекции)

y = 5√(sin(x²+3x+5)) = (sin(x²+3x+5))1/5. Три слоя: степень → sin → многочлен.

y′ = 15(sin u)−4/5·cos u·(2x+3),  где u = x²+3x+5.
= (2x + 3)·cos(x²+3x+5)5·5√(sin⁴(x²+3x+5)).

Сам: y = cos(2x)/(1 + sin 2x). Найди y′.

Решение
Частное: f = cos2x (f′ = −2sin2x), g = 1+sin2x (g′ = 2cos2x).
y′ = −2sin2x·(1+sin2x) − cos2x·2cos2x(1+sin2x)² = −2sin2x − 2sin²2x − 2cos²2x(1+sin2x)².
Используем sin² + cos² = 1: числитель = −2sin2x − 2 = −2(1 + sin2x). Сокращаем: y′ = −21 + sin2x.

Логарифмическое дифференцирование

Когда применять

Если переменная стоит и в основании, и в показателе (как xx), или функция — это длинное произведение/частное корней. Сначала логарифмируем, тогда степени станут множителями, а произведения — суммами.

Схема

Пусть y = y(x). Прологарифмируем: ln y = ln y(x). Продифференцируем обе части (слева по цепному правилу (ln y)′ = y′/y):

y′(x) = y(x)·(ln y(x))′
Классика: (xˣ)′
Обозначим саму функцию за y, то есть y = xˣ (это и есть то, что дифференцируем). Теперь прологарифмируем обе части:
ln y = ln xˣ = x·ln x.  (слева ln y, потому что y = xˣ)
(x·ln x)′ = 1·ln x + x·1x = ln x + 1.
y′ = y·(ln x + 1) = xˣ(ln x + 1).
Корень из дроби (из лекции)

y = √(x(x−1)x−2).

ln y = 12·[ln x + ln(x−1) − ln(x−2)].
(ln y)′ = 12·[1x + 1x−1 − 1x−2].
y′ = 12·√(x(x−1)x−2)·[1x + 1x−1 − 1x−2].

Задачи для разбора

Сначала попробуй сам, потом раскрой решение.

1. y = x2/3·sin 2x (из лекции).

Решение
Произведение: f = x2/3 (f′ = 23x−1/3), g = sin2x (g′ = 2cos2x).
y′ = 23x−1/3·sin2x + x2/3·2cos2x = 2 sin2x3·3√x + 2x2/3cos2x.

2. y = (3x + 1)10.

Решение
Цепное: внешняя (…)10, внутренняя 3x+1 (производная 3).
y′ = 10(3x+1)⁹·3 = 30(3x + 1)⁹.

3. y = ln√(1 + x²1 − x²) (из лекции).

Решение
Упростим логарифм: y = 12[ln(1+x²) − ln(1−x²)].
y′ = 12[2x1+x² − −2x1−x²] = x1+x² + x1−x².
Складываем дроби: = x(1−x²) + x(1+x²)(1+x²)(1−x²) = 2x1 − x⁴.

4. y = e3x·cos x.

Решение
Произведение: (e3x)′ = 3e3x, (cos x)′ = −sin x.
y′ = 3e3xcos x − e3xsin x = e3x(3cos x − sin x).

5. y = (sin x)x (логарифмическое).

Решение
ln y = x·ln(sin x). Дифференцируем: (x ln sin x)′ = ln sin x + x·cos xsin x = ln sin x + x·ctg x.
y′ = (sin x)x·(ln sin x + x·ctg x).

6. Напиши уравнение касательной к y = x³ в точке x₀ = 1.

Решение
f(1) = 1;  f′(x) = 3x² ⟹ f′(1) = 3.
y = 1 + 3(x − 1) = 3x − 2.

Односторонние производные

Определение

Можно считать предел Δy/Δx только справа или только слева:

f′₋(x₀) = limΔx→0− ΔyΔx  (слева),    f′₊(x₀) = limΔx→0+ ΔyΔx  (справа)

Производная существует ⟺ обе односторонние конечны и равны: f′₋ = f′₊.

Разбор: y = |x| в точке 0

Справа (x > 0): |x| = x, наклон +1 ⟹ f′₊(0) = +1. Слева (x < 0): |x| = −x, наклон −1 ⟹ f′₋(0) = −1.

+1 ≠ −1 ⟹ производной в нуле нет. На графике это «угол» — резкая смена направления, одной касательной не провести.

В «угле» наклон слева (−1) и справа (+1) разные ⟹ производной нет. Там, где график гладкий (например x²), слева и справа наклон один и тот же — производная есть.

Что значит «функция дифференцируема»

Определение

Функция дифференцируема в x₀, если её приращение раскладывается на линейную часть плюс бесконечно малую высшего порядка:

Δy = A·Δx + o(Δx),   A = const

Коэффициент A — это и есть производная: A = f′(x₀). То есть дифференцируемость ⟺ существует конечная производная.

На числах: f = x², x₀ = 3
Δy = (3 + Δx)² − 3² = 9 + 6Δx + Δx² − 9 = 6·Δx + Δx².
Линейная часть: 6·Δx ⟹ A = 6 = f′(3). Остаток Δx² — это o(Δx), ведь Δx²/Δx = Δx → 0.
Значит f(x)=x² дифференцируема в 3, и f′(3) = 6.
Дифференциал

Линейную часть приращения называют дифференциалом:  dy = f′(x₀)·dx. Это удобное приближение: при малом Δx  Δy ≈ f′(x₀)·Δx.

Приближённое вычисление: √4,1
Берём f(x) = √x, x₀ = 4 (знаем √4 = 2), Δx = 0,1.  f′(x) = 1/(2√x) ⟹ f′(4) = 1/4.
√4,1 ≈ f(4) + f′(4)·0,1 = 2 + 0,25·0,1 = 2,025. (Точное значение 2,0248… — почти совпало.)

Связь с непрерывностью

Теорема

Если f дифференцируема в x₀, то она непрерывна в x₀.

Почему: Δy = f′(x₀)·Δx + o(Δx). При Δx → 0 правая часть → 0, значит Δy → 0 — а это и есть непрерывность (приращение функции стремится к нулю).
Обратное неверно!

Непрерывность не гарантирует дифференцируемость. Пример — та же y = |x|: в нуле она непрерывна (график не разрывается), но производной нет (угол). Гладкость — более сильное требование, чем непрерывность.

Короткая логика: есть производная ⟹ гладко ⟹ непрерывно. Непрерывно ⟹ без разрывов, но могут быть «углы» ⟹ производной может и не быть.

Касательная и нормаль

Две прямые в точке M(x₀, f(x₀))

Касательная — наклон равен производной:

y = f(x₀) + f′(x₀)·(x − x₀)

Нормаль — перпендикуляр к касательной. У перпендикулярных прямых k₁·k₂ = −1, значит наклон нормали = −1/f′(x₀):

y = f(x₀) − 1f′(x₀)·(x − x₀)
На числах: f = x², x₀ = 1
f(1) = 1;  f′(x) = 2x ⟹ f′(1) = 2.
Касательная: y = 1 + 2(x − 1) = 2x − 1.
Нормаль: наклон = −1/2. y = 1 − 12(x − 1) = −x2 + 32.
Проверка перпендикулярности: 2 · (−1/2) = −1 ✓.
Касательная (золотая) и нормаль (розовая) пересекаются в точке касания под прямым углом. Наклоны: 2 и −1/2, произведение −1.

Как составить уравнение касательной — алгоритм

  1. Шаг 1. Вычисли значение функции в точке: f(x₀).
  2. Шаг 2. Найди производную f′(x) и подставь точку: f′(x₀) — это наклon.
  3. Шаг 3. Подставь в формулу y = f(x₀) + f′(x₀)·(x − x₀) и упрости.

Ниже — касательные к функциям посложнее. Сначала попробуй сам.

1. Касательная к y = ln x в точке x₀ = 1.

Решение
f(1) = ln 1 = 0.  f′(x) = 1/x ⟹ f′(1) = 1.
y = 0 + 1·(x − 1) = x − 1.

2. Касательная к y = √x в точке x₀ = 4.

Решение
f(4) = 2.  f′(x) = 12√x ⟹ f′(4) = 14.
y = 2 + 14(x − 4) = x4 + 1.

3. Касательная к y = x³ − 3x в точке x₀ = 2.

Решение
f(2) = 8 − 6 = 2.  f′(x) = 3x² − 3 ⟹ f′(2) = 12 − 3 = 9.
y = 2 + 9(x − 2) = 9x − 16.

4. Касательная к y = x·ln x в точке x₀ = 1.

Решение
f(1) = 1·0 = 0.  f′(x) = ln x + x·1x = ln x + 1 ⟹ f′(1) = 0 + 1 = 1.
y = 0 + 1·(x − 1) = x − 1.

5. Касательная к y = ex в точке x₀ = 0, и нормаль там же.

Решение
f(0) = 1.  f′(x) = ex ⟹ f′(0) = 1.
Касательная: y = 1 + 1·(x − 0) = x + 1.
Нормаль: наклон −1/1 = −1 ⟹ y = 1 − (x − 0) = −x + 1.

6. (Обратная задача) Найди касательную к y = x², которая параллельна прямой y = 4x.

Решение
Параллельна ⟹ одинаковый наклон: f′(x₀) = 4. Но f′(x) = 2x ⟹ 2x₀ = 4 ⟹ x₀ = 2.
Точка касания: f(2) = 4. Касательная: y = 4 + 4(x − 2) = 4x − 4.
Здесь мы шли «от наклона к точке» — частый тип задач.

7. Где касательная к y = x³ − 3x горизонтальна?

Решение
Горизонтальна ⟺ наклон 0: f′(x) = 3x² − 3 = 0 ⟹ x² = 1 ⟹ x = ±1.
В x = 1: f(1) = −2 ⟹ касательная y = −2. В x = −1: f(−1) = 2 ⟹ y = 2. Это «вершины» графика.

Производная обратной функции

Правило

Если у y = f(x) есть обратная x = φ(y) и f′(x₀) ≠ 0, то

φ′(y₀) = 1f′(x₀)

«Производная обратной — это единица делить на производную прямой.» Геометрически: графики f и φ симметричны относительно прямой y = x, их наклоны взаимно обратны.

Проверка на числах: y = x³
f(x) = x³, f′(x) = 3x². В точке x = 2: f′(2) = 12, и y = 8.
Обратная: x = y1/3. По правилу её производная в y = 8 равна 1/12.
Прямой подсчёт: (y1/3)′ = 13y−2/3 = 13·8−2/3 = 13·14 = 1/12 ✓.
Так выводят табличные формулы

(arcsin x)′: y = arcsin x ⟹ x = sin y, x′(y) = cos y. Тогда y′ = 1/cos y = 1/√(1−sin²y) = 1/√(1−x²).

(ln x)′: y = ln x ⟹ x = ey, x′(y) = ey. Тогда y′ = 1/ey = 1/eln x = 1/x.

Ещё задачи

1. Выведи (arctg x)′ через обратную функцию.

Решение
y = arctg x ⟹ x = tg y,  x′(y) = 1cos²y = 1 + tg²y = 1 + x².
y′ = 1x′(y) = 11 + x².

2. Выведи (arccos x)′.

Решение
y = arccos x ⟹ x = cos y,  x′(y) = −sin y.
y′ = 1−sin y = −1√(1−cos²y) = −1√(1−x²).

3. Для y = x⁵ найди производную обратной функции в точке x = 1 (то есть y = 1).

Решение
f′(x) = 5x⁴ ⟹ f′(1) = 5. Значит производная обратной в y = 1 равна 1/5.
Проверка: обратная x = y1/5, (y1/5)′ = 15y−4/5, в y = 1: 1/5 ✓.

4. (√x)′ как производная функции, обратной к x².

Решение
Пусть y = √x — обратная к x = y² (при y ≥ 0). x′(y) = 2y.
y′ = 12y = 12√x ✓ — знакомая табличная формула.

Производная параметрической функции

Правило

Если кривая задана через параметр: x = φ(t), y = ψ(t), то

dydx = ψ′(t)φ′(t) = y′tx′t

Считаем производные x и y по t отдельно и делим.

Простой пример: x = t², y = t³
x′t = 2t,  y′t = 3t².  dydx = 3t²2t = 3t2.
При t = 2: точка (x, y) = (4, 8), наклon касательной = 3·2/2 = 3.
Из лекции: x = ln(1+t²), y = t − arctg t
x′t = 2t1+t²;  y′t = 1 − 11+t² = t²1+t².
dydx = t²/(1+t²)2t/(1+t²) = t²2t = t2.
Вторая производная

y″xx = (y′x)′tx′t — снова делим производную по t на x′t.

Для x = t², y = t³
y′x = 3t/2. Берём её производную по t: (3t/2)′t = 3/2. Делим на x′t = 2t:
y″xx = 3/22t = 34t. При t = 2: y″ = 3/8.

Ещё задачи

1. x = 2t, y = t². Найди dy/dx.

Решение
x′t = 2,  y′t = 2t.  dydx = 2t2 = t. (Это та же парабола y = x²/4, и правда dy/dx = x/2 = t.)

2. Окружность x = cos t, y = sin t. Найди dy/dx и наклон при t = π/4.

Решение
x′t = −sin t,  y′t = cos t.  dydx = cos t−sin t = −ctg t.
При t = π/4: −ctg(π/4) = −1 (касательная к окружности под 45°).

3. x = et, y = e−t. Найди dy/dx.

Решение
x′t = et,  y′t = −e−t.  dydx = −e−tet = −e−2t.

4. Циклоида x = t − sin t, y = 1 − cos t. Найди dy/dx.

Решение
x′t = 1 − cos t,  y′t = sin t.  dydx = sin t1 − cos t.
Можно упростить через половинный угол: = ctg(t/2) (sin t = 2sin(t/2)cos(t/2), 1−cos t = 2sin²(t/2)).

Дифференцирование неявной функции

Идея

Иногда y не выражен явно, а связан с x уравнением F(x, y) = 0 (например, окружность x²+y²=25). Тогда дифференцируем всё уравнение по x, помня, что y — это функция от x (поэтому y² даёт 2y·y′ по цепному правилу), и выражаем y′.

Разминка: окружность x² + y² = 25
Дифференцируем по x: 2x + 2y·y′ = 0 ⟹ y′ = −x/y.
В точке (3, 4): y′ = −3/4 (наклон касательной к окружности).
Из лекции: x³ − 2x²y² + 5x + y − 5 = 0, найти y′(1), если y(1) = 1
Дифференцируем почленно по x (у члена 2x²y² — правило произведения, и y²→2y·y′):
3x² − (4x·y² + 2x²·2y·y′) + 5 + y′ = 0  ⟹  3x² − 4xy² − 4x²y·y′ + 5 + y′ = 0.
Собираем y′:  y′·(1 − 4x²y) = 4xy² − 3x² − 5  ⟹  y′ = 4xy² − 3x² − 51 − 4x²y.
Подставляем x = 1, y = 1:  y′(1) = 4 − 3 − 51 − 4 = −4−3 = 43.

Ещё задачи

Правило одно: дифференцируем обе части по x, у каждого y появляется множитель y′, затем собираем y′.

1. xy = 1. Найди y′.

Решение
(xy)′ = 1·y + x·y′ = 0 (производная правой части 1 — ноль).
y + x·y′ = 0 ⟹ y′ = −yx. (Это y = 1/x, и правда y′ = −1/x² = −y/x.)

2. x² + xy + y² = 7. Найди y′, затем y′ в точке (1, 2).

Решение
Дифференцируем: 2x + (y + x·y′) + 2y·y′ = 0  (у члена xy — произведение).
Собираем y′: y′(x + 2y) = −(2x + y) ⟹ y′ = −2x + yx + 2y.
В точке (1, 2): y′ = −2 + 21 + 4 = −45.

3. ey + xy = e. Найди y′ в точке (0, 1).

Решение
Дифференцируем: ey·y′ + (y + x·y′) = 0 ⟹ y′(ey + x) = −y ⟹ y′ = −yey + x.
В точке (0, 1): y′ = −1e¹ + 0 = −1e.

4. Найди касательную к окружности x² + y² = 25 в точке (3, 4).

Решение
Неявно: 2x + 2y·y′ = 0 ⟹ y′ = −x/y. В точке (3,4): y′ = −3/4 — это наклон.
Касательная: y = 4 − 34(x − 3) = −34x + 254. (Связали неявную функцию с касательной — как ты и просил.)
